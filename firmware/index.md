## ⚡ 변신 방법 (30초)

```
① 앱 열기  →  ② 펌웨어 메뉴  →  ③ 원하는 프로파일 탭  →  ④ DFU 진행 (30초~1분)
```

- 데이터 손실 없이 프로파일만 교체
- 배터리 30% 이상에서 실행 권장
- 진행 중 USB 전원 유지

---

## 🧠 왜 멀티 프로파일인가

경쟁사: 한 보드 → 한 용도. 용도별로 여러 보드를 사야 함.  
**ELIO: 한 보드 → 네 용도. 장난감을 샀는데, 네 번 산 것과 같음.**
