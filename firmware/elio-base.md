# 🔹 elio-base — 기본 프로파일

> 박스에서 처음 꺼냈을 때 기본으로 탑재되는 펌웨어. DC·서보·IO의 핵심 기능만 가볍게.

## 지원 기능

| 기능 | 포트 | 범위 |
|------|------|------|
| DC 모터 | DC1 · DC2 | -100 ~ +100 % |
| 서보 | SV1 · SV2 | 0 ~ 180° |
| 전원 출력 | 3V · 5V | on / off |
| 디지털 IO | IO1 ~ IO4 | on / off 또는 PWM |

## 추천 프로젝트

- 🚗 스마트폰 RC 카
- 🦾 간단한 2축 로봇팔
- 💡 원격 LED 제어
