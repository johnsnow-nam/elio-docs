# Block-Code Your Robot with Entry (Korean Coding Platform)

**Platform**: Instructables  
**Status**: 🔲 Frame only (Wave 1) — full content in Wave 2  
**Target audience**: Educators, students, parents in Korea; global makers curious about Entry  
**Est. read time**: 15 minutes  
**Est. build time**: 30 minutes (setup) + 1 hour (projects)

---

## Introduction (Outline)

> Entry is Korea's #1 block coding platform — used in 90%+ of Korean schools. ELIO connects to it over USB dongle, letting students drag-and-drop their robot to life.

**Key hook**: "If you're teaching robotics in a Korean classroom, this is the setup guide you've been looking for."

**What we'll build**: An Entry-controlled RC car with obstacle avoidance blocks.

---

## Supplies (Outline)

- ELIO board
- USB dongle (nRF52840, included in kit)
- PC (Windows or macOS)
- Entry HW app (free download)
- Smartphone (for initial test)

---

## Steps (Outline)

1. Install Entry HW desktop app
2. Connect USB dongle
3. Select ELIO hardware in Entry
4. First blocks: move forward, turn left/right
5. Add a sensor: ultrasonic distance
6. Build obstacle avoidance program
7. Challenge: line-following with line sensors
