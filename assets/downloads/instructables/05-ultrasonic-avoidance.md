# Obstacle Avoidance Robot with Ultrasonic Sensor

**Platform**: Instructables  
**Status**: 🔲 Frame only (Wave 1) — full content in Wave 2  
**Target audience**: Beginners to intermediate; STEM education  
**Est. read time**: 10 minutes  
**Est. build time**: 45 minutes

---

## Introduction (Outline)

> ELIO's elio-sensor firmware packs ultrasonic, line, and light sensors. This tutorial activates the ultrasonic sensor to build a robot that dodges obstacles automatically.

**Key hook**: "From remote-controlled toy to autonomous robot — one firmware switch."

**What we'll build**: Autonomous obstacle-avoiding RC car using elio-sensor firmware + Entry or Python control.

---

## Supplies (Outline)

- ELIO board with elio-sensor firmware
- HC-SR04 ultrasonic sensor (or ELIO built-in)
- Chassis + motors
- Entry HW / Python for logic

---

## Steps (Outline)

1. Flash elio-sensor firmware (in-app DFU)
2. Connect ultrasonic sensor to ELIO
3. Test sensor readings in app
4. Entry blocks: if distance < 20cm → stop + turn
5. Python version: sensor polling loop
6. Tuning: threshold distance, turn angle
7. Challenge: maze navigation
