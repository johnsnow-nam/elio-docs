# ELIO + Arduino: Two Boards Talking via UART

**Platform**: Instructables  
**Status**: 🔲 Frame only (Wave 1) — full content in Wave 2  
**Target audience**: Arduino users, intermediate makers  
**Est. read time**: 12 minutes  
**Est. build time**: 1 hour

---

## Introduction (Outline)

> You already have an Arduino. Don't replace it — pair it with ELIO. Arduino handles your complex shields and sensors; ELIO handles motors, BLE, and smartphone control.

**Key hook**: "What if your Arduino could control a smartphone-connected robot? Three wires is all it takes."

**What we'll build**: Arduino + ELIO RC car, controlled by Arduino logic AND smartphone simultaneously.

---

## Supplies (Outline)

- Arduino Uno or Nano (3.3V version recommended, or use level shifter)
- ELIO board (Gen3 / ELIO-52810)
- 3 jumper wires (TX, RX, GND)
- Level shifter (if using 5V Arduino)
- ELIO Arduino library

---

## Steps (Outline)

1. Understanding the UART protocol
2. Wiring (TX/RX crossover + level shifter note)
3. Installing the ELIO Arduino library
4. First sketch: forward + stop
5. Reading sensor data back from ELIO
6. Building a combined app+Arduino control system
7. Project: Arduino ultrasonic shield + ELIO motors
