## 🔍 ELIO 보드 살펴보기

```
       ┌───────────────────────────────────┐
       │   [LED1]   [LED2]                │
       │                                   │
       │  [DC1]───[DC2]    [SV1]─[SV2]   │  ← 모터 · 서보 포트
       │                                   │
       │  [IO1][IO2][IO3][IO4]             │  ← 디지털 IO
       │  [3V]           [5V]              │  ← 전원 출력
       │                                   │
       │      [USB-C / USB]   [Power SW]  │
       │                                   │
       └───────────────────────────────────┘
```

### 주요 포트

| 표시 | 뭐인가요 | 언제 쓰나요 |
|------|---------|-------------|
| **DC1 / DC2** | DC 모터 2개 | 바퀴·프로펠러 회전 |
| **SV1 / SV2** | 서보 모터 2개 | 팔·머리 회전 (각도 제어) |
| **3V / 5V** | 전원 출력 | 센서에 전원 공급 |
| **IO1 ~ IO4** | 범용 입출력 | 센서 신호·스위치·LED |

## 💡 LED 상태 표시

| LED 패턴 | 의미 |
|---------|------|
| **천천히 깜빡임** (1초) | 광고 중 (앱 연결 대기) |
| **빠르게 깜빡임** (0.1초) | 모터 오류 (과전류 등) |
| **꺼짐** | 전원 없음 또는 연결됨 |

---

## ⚡ 전원 켜기

1. USB-C 케이블을 ELIO에 연결
2. 반대쪽을 보조배터리·노트북·충전기에 연결
3. LED가 **천천히 깜빡이기 시작**하면 성공

> **전원이 안 켜지나요?** USB 케이블을 데이터 전송 가능한 것으로 바꿔보세요 (싸구려 충전 전용 케이블은 간혹 동작 안 함).
