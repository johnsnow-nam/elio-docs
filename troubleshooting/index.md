# 🆘 문제 해결 가이드

> 대부분의 문제는 **전원·배선·앱 재시작** 3가지로 해결됩니다.

---

## 빠른 체크리스트

문제가 생기면 먼저 이것부터:

- [ ] ELIO 배터리 충전 상태 확인 (LED 꺼짐 = 방전)
- [ ] 앱 완전 종료 후 재시작
- [ ] ELIO 전원 껐다 켜기
- [ ] 스마트폰 블루투스 껐다 켜기

---

## 🔵 BLE 연결 문제

### Q: 앱에서 ELIO가 검색되지 않아요

1. ELIO 전원이 켜져 있는지 확인 (파란 LED 점멸 = 스캔 중)
2. 스마트폰 블루투스 ON 확인
3. 스마트폰 위치 권한 허용 확인 (Android BLE 필수)
4. ELIO 전원 껐다 켜기
5. 앱 완전 종료 후 재실행

### Q: 검색은 되는데 연결이 안 돼요

- ELIO가 이미 다른 기기와 페어링됐을 수 있음 → 다른 기기의 앱 종료 또는 ELIO 재시작
- ELIO 전원 껐다 켜기 (BLE 페어링 초기화)

### Q: 연결됐다가 자꾸 끊겨요

- ELIO와 스마트폰 거리 확인 (BLE 유효 범위: ~10m 실내)
- 전자기기(전자레인지, WiFi 공유기 등)와 거리 유지
- 배터리 잔량 확인 — 방전 시 BLE 출력 저하로 끊김 빈번

## ⚡ 전원·LED 문제

### Q: 전원 버튼을 눌러도 LED가 켜지지 않아요

- 배터리 완전 방전 → USB-C 케이블로 충전 (30분 이상)
- 충전 중에는 빨간 LED 점등, 완충 시 파란 LED 점등 또는 소등 (보드 버전에 따라 다름)

### Q: LED 색상이 평소와 다릅니다

| LED 상태 | 의미 |
|----------|------|
| 파란색 점멸 | BLE 스캔 중 (정상) |
| 파란색 점등 | BLE 연결됨 (정상) |
| 빨간색 점등 | 충전 중 |
| LED 꺼짐 | 전원 OFF 또는 배터리 방전 |
| 빠른 빨간색 점멸 | 과방전 또는 펌웨어 오류 |

### Q: 충전이 안 돼요

- USB-C 케이블 불량 여부 확인 (다른 케이블 시도)
- USB 충전기 출력 확인 (5V 1A 이상 권장)
- 과열 후 충전 보호 회로 동작 → 5분 식힌 후 재시도

## 🏎 모터·구동 문제

### Q: 앱에서 명령을 보내도 모터가 안 움직여요

- 펌웨어 프로파일 확인 — `elio-base` 또는 `elio-servo` 프로파일인지 확인
- 모터 커넥터 꽂힘 확인 (DC 모터 포트: DC1/DC2)
- 배터리 잔량 확인 — 모터는 배터리 소모가 큼

### Q: 한 방향으로만 회전해요 (역방향 안 됨)

- 앱에서 음수 값(역방향)이 제대로 전송되는지 확인
- 모터 배선 극성 확인 — 빨간선/검은선 방향 바꿔보기

### Q: 왼쪽·오른쪽 모터 속도가 달라요

- DC1/DC2 포트 각각 속도 보정값 조절 (앱 설정 내 캘리브레이션)
- 모터 자체 특성 차이 — 동일 사양 모터로 교체 권장

### Q: 서보가 제자리에서 떨려요 (지터)

- 전원 공급 부족 → 서보와 ELIO를 별도 전원으로 분리
- 서보 제어 신호 주파수 확인 — `elio-servo` 프로파일 권장

## 📱 앱 문제

### Q: iOS에서 "블루투스 사용 권한" 팝업이 안 떠요

- 설정 → 개인정보 보호 → 블루투스 → bletoy 앱 허용
- 앱 삭제 후 재설치

### Q: Android에서 BLE 스캔이 안 됩니다

- 설정 → 앱 → bletoy → 권한 → **위치(정밀)** 허용
- Android 12 이상: **주변 기기** 권한도 허용
- 앱 완전 종료 후 재시작

### Q: 앱이 충돌하거나 강제 종료돼요

- 앱 최신 버전 확인 (Play Store / App Store 업데이트)
- 앱 캐시 초기화 (Android: 앱 설정 → 저장소 → 캐시 삭제)
- 폰 재시작

## 💾 펌웨어·DFU 문제

### Q: DFU(펌웨어 업데이트) 중에 실패해요

- 배터리 충분한지 확인 (50% 이상 권장)
- DFU 중 앱 백그라운드 전환 금지
- BLE 연결 안정성 확인 (가까이서 진행)
- 실패 시 ELIO 재시작 후 재시도 — 일반적으로 이전 펌웨어로 자동 복구

### Q: 펌웨어 업데이트 후 ELIO가 응답 없어요

- ELIO 전원 껐다 켜기 (부팅 완료까지 10초 대기)
- 그래도 안 되면 앱에서 DFU 모드 재진입 시도
- 최후 수단: USB로 연결 후 nRF Connect DFU 앱 사용

---

## 🔌 커넥터·배선 문제

### Q: 레고 모터가 ELIO에서 안 움직여요

- 레고 모터 젠더(어댑터) 사용 여부 확인
- 커넥터 방향 확인 (레고 전선 커넥터는 방향성 있음)
- `elio-base` 또는 `elio-servo` 프로파일에서 모터 테스트

### Q: UART 직결에서 ELIO가 응답 없어요

- TX/RX 교차 연결 확인 (어댑터 TX → ELIO RX)
- Baud rate 115,200 확인
- 세대3 (ELIO-52810) 보드인지 확인 (세대1/2는 UART 직결 미지원)
- 레벨 시프터 필요 여부 확인 (5V 로직 어댑터 사용 시)
