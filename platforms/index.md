# 💻 코딩 플랫폼

> ELIO는 **어떤 코딩 환경에서도 동작**합니다. 블록 코딩 초심자부터 Python 전문가까지.

---

## 🗺 플랫폼 선택 가이드

| 플랫폼 | 대상 | 연결 방식 | 준비물 |
|--------|------|-----------|--------|
| [**Entry (엔트리)**](/platforms/entry/) | 초·중학생, 교사 | USB 동글 | ELIO + USB 동글 + PC |
| [**Scratch 3.0**](/platforms/scratch/) | 전 연령, 글로벌 | USB 동글 | ELIO + USB 동글 + Chrome |
| [**Python**](/platforms/python/) | 중학생~대학생, 메이커 | UART 직결 | ELIO + USB-UART 어댑터 |

---

## 🔌 두 가지 연결 경로

### 경로 🅱 USB 동글 경유 (Entry / Scratch)
```
PC / 크롬 ──USB── [USB 동글] ──BLE── ELIO
```
- **동글 필수** (별도 구매, 원가 약 11,000원)
- 블록 코딩에 최적화

### 경로 🅲 UART 직결 (Python)
```
PC ──USB-UART 어댑터──TX/RX/GND── ELIO
```
- **동글 불필요**, USB-UART 어댑터만 있으면 됨
- 텍스트 코딩·AI 프로젝트에 적합
- **세대3 (ELIO-52810) 전용**

## 🚀 빠른 시작 추천 경로

```

  ↓

  ↓

```
