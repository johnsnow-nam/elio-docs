# 단원 7: 자율 주행 자동차 만들기 1

## 학습 목표

| 항목 | 내용 |
|------|------|
| 주제 | 자율주행 기초 |
| 난이도 | 중급-고급 |
| 소요시간 | 2시간 |
| 학습 내용 | 센서 활용, 경로 인식, 기본 제어 |

## 개요

라인센서를 이용한 자율 주행 자동차의 기초를 배우는 프로젝트입니다. 정해진 경로를 따라 자동으로 이동합니다.

## 주요 학습 내용

### 준비물
- ELIO 로봇
- 라인센서 2개 이상
- DC 모터 2개
- 검은색 테이프로 만든 경로
- 스크래치 환경

### 기본 개념
- 센서 기반 피드백 제어
- 차등 구동(Differential Drive)
- 모터 속도 조정
- 경로 추적 알고리즘

### 코딩 요소
- 다중 센서 읽기
- 조건부 모터 제어
- 무한 루프 제어
- 상수값 활용

![이미지](/elio-docs/assets/images/education/elio-vol4/ch01-slide2.jpg)

## 학습 단계

#### 1단계: 센서 보정
좌우 센서의 기준값을 설정합니다.

#### 2단계: 직진 주행
직선 경로에서 일정한 속도로 움직입니다.

#### 3단계: 회전 처리
곡선 경로에서 부드럽게 회전합니다.

## 심화 학습

- 고속 주행
- 복잡한 경로 추적
- 장애물 회피
