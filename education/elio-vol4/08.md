# 단원 8: 자율 주행 자동차 만들기 2

## 학습 목표

| 항목 | 내용 |
|------|------|
| 주제 | 자율주행 고급 |
| 난이도 | 고급 |
| 소요시간 | 2시간 |
| 학습 내용 | PID 제어, 최적화, 실전 응용 |

## 개요

1단계의 기초를 바탕으로 PID 제어를 적용하여 더욱 정확하고 부드러운 자율 주행을 구현합니다.

## 주요 학습 내용

### 준비물
- ELIO 로봇
- 라인센서 2개 이상
- DC 모터 2개
- 검은색 테이프 경로 (다양한 곡선)
- 스크래치 환경

### 기본 개념
- PID 제어의 기초 (P, I, D)
- 오차 계산 및 보정
- 파라미터 튜닝
- 정상상태 도달

### 코딩 요소
- 변수를 통한 파라미터 저장
- 오차 계산 및 적분/미분
- 복잡한 조건문
- 상태 모니터링

## 📷 [이미지: PID 제어 응용]

## 학습 단계

#### 1단계: 비례(P) 제어
오차에 비례하는 보정을 적용합니다.

#### 2단계: 적분(I) 제어
누적 오차를 고려하여 미세 조정합니다.

#### 3단계: 미분(D) 제어
오차 변화율을 고려하여 안정성을 향상시킵니다.

## 심화 학습

- 파라미터 자동 최적화
- 장애물 회피 추가
- 목표 지점 도달 조건
