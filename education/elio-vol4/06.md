# 단원 6: 슈팅 게임 만들기 4

## 학습 목표

| 항목 | 내용 |
|------|------|
| 주제 | 게임 완성 및 폴리쉬 |
| 난이도 | 고급 |
| 소요시간 | 2시간 |
| 학습 내용 | 사운드, 비주얼, 게임 오버 화면 |

## 개요

슈팅 게임에 사운드 효과, 시각적 개선, 게임 오버/승리 화면을 추가하여 완성합니다.

## 주요 학습 내용

### 준비물
- ELIO 로봇
- 스크래치 환경
- 완성된 3단계 게임

### 기본 개념
- 사운드 효과 활용
- 애니메이션 및 화면 효과
- UI 디자인
- 게임 상태 화면 전환

### 코딩 요소
- `소리 재생` 블록
- 스프라이트 애니메이션
- 배경음악 루프
- 화면 전환 로직

## 📷 [이미지: 완성된 슈팅 게임]

## 학습 단계

#### 1단계: 사운드 추가
발사음, 폭발음 등을 추가합니다.

#### 2단계: 비주얼 개선
애니메이션과 파티클 효과를 추가합니다.

#### 3단계: 게임 화면 완성
시작 화면, 게임 오버 화면, 승리 화면을 만듭니다.

## 심화 학습

- 배경음악 작곡
- 캐릭터 디자인
- 리더보드 시스템
