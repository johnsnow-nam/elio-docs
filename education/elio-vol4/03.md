# 단원 3: 슈팅 게임 만들기 1

## 학습 목표

| 항목 | 내용 |
|------|------|
| 주제 | 슈팅 게임 기초 |
| 난이도 | 중급 |
| 소요시간 | 1.5시간 |
| 학습 내용 | 스프라이트 관리, 키 입력 처리 |

## 개요

플레이어 캐릭터를 조작하고 기본 슈팅 메커니즘을 구현하는 게임입니다. 1단계에서는 플레이어 이동과 발사 기본을 배웁니다.

## 주요 학습 내용

### 준비물
- ELIO 로봇
- 스크래치 환경
- 키보드 또는 게임패드

### 기본 개념
- 플레이어 스프라이트 제어
- 키보드 입력 감지
- 총알 생성 및 관리
- 기본 충돌 감지

### 코딩 요소
- `키 눌렀는가` 블록
- `변수` 업데이트
- `클론` 생성으로 총알 구현
- 간단한 충돌 검사

## 📷 [이미지: 슈팅 게임 1단계]

## 학습 단계

#### 1단계: 플레이어 이동
좌우 화살표 키로 플레이어를 움직입니다.

#### 2단계: 총알 발사
스페이스바로 총알을 발사합니다.

#### 3단계: 적 배치
간단한 적을 화면에 배치합니다.

## 심화 학습

- 이동 속도 조정
- 발사 속도 제한
- 화면 끝 경계 처리
