# 단원 4: 슈팅 게임 만들기 2

## 학습 목표

| 항목 | 내용 |
|------|------|
| 주제 | 충돌 감지 및 점수 |
| 난이도 | 중급 |
| 소요시간 | 1.5시간 |
| 학습 내용 | 충돌 검사, 점수 계산, 게임 상태 |

## 개요

슈팅 게임에 충돌 감지, 점수 계산, 게임 오버 기능을 추가합니다.

## 주요 학습 내용

### 준비물
- ELIO 로봇
- 스크래치 환경
- 완성된 1단계 게임

### 기본 개념
- 스프라이트 간 충돌 감지
- 점수 계산 및 표시
- 게임 오버 조건
- 상태 관리

### 코딩 요소
- `충돌했는가` 블록
- 변수를 통한 점수 관리
- `모든 클론 삭제` 블록
- 게임 종료 로직

![이미지](/elio-docs/assets/images/education/elio-vol4/ch01-slide2.jpg)

## 학습 단계

#### 1단계: 충돌 감지 구현
총알과 적이 충돌했을 때를 감지합니다.

#### 2단계: 점수 시스템
적을 격추하면 점수를 얻습니다.

#### 3단계: 게임 오버
플레이어가 피격되면 게임이 끝납니다.

## 심화 학습

- 생명(HP) 시스템
- 레벨 진행
- 점수 기록
