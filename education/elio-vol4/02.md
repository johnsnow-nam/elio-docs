# 카드 뒤집기 게임 만들기 2

## 학습 목표

| 목표 | 설명 |
|------|------|
| 스프라이트 생성 | 모양을 스프라이트로 변환 |
| 변수 활용 | 게임 상태를 관리하는 변수 만들기 |
| 반복 블록 | 여러 카드를 효율적으로 배치하기 |
| 클릭 이벤트 | 마우스 이벤트 처리 |

## 학습 내용

### 1. 카드 스프라이트 만들기
그린 모양들을 스프라이트로 변환하여 게임의 객체로 만듭니다.

### 2. 카드 배치
반복 블록을 사용하여 18개의 카드를 가로 6개, 세로 3개로 배치합니다. 각 카드의 위치를 계산하여 정렬합니다.

### 3. 클릭 이벤트 처리
카드가 클릭되면 뒤집히고, 선택한 카드가 같은 짝인지 확인하는 로직을 구현합니다.

### 4. 게임 상태 관리
게임의 상태(초기화, 진행 중, 종료)를 변수로 관리하여 게임 흐름을 제어합니다.

### 5. 점수 계산
짝을 맞춘 카드의 개수에 따라 점수가 올라갑니다. 모든 카드를 맞추면 게임이 종료됩니다.
