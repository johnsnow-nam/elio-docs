# 단원 5: 슈팅 게임 만들기 3

## 학습 목표

| 항목 | 내용 |
|------|------|
| 주제 | 게임 요소 확대 |
| 난이도 | 중급-고급 |
| 소요시간 | 2시간 |
| 학습 내용 | 다중 적 관리, 웨이브 시스템 |

## 개요

여러 종류의 적을 관리하고 웨이브 기반 진행을 추가합니다.

## 주요 학습 내용

### 준비물
- ELIO 로봇
- 스크래치 환경
- 완성된 2단계 게임

### 기본 개념
- 여러 스프라이트 타입 관리
- 웨이브 및 라운드 시스템
- 난이도 점진적 증가
- 메모리 효율적 관리

### 코딩 요소
- 리스트로 적 배치
- 루프를 통한 반복 생성
- 변수 업데이트로 난이도 조정
- 다중 조건 체크

![이미지](/elio-docs/assets/images/education/elio-vol4/ch01-slide2.jpg)

## 학습 단계

#### 1단계: 여러 적 동시 생성
리스트를 이용하여 많은 적을 관리합니다.

#### 2단계: 웨이브 시스템
일정 수의 적을 격추하면 다음 웨이브로 진행합니다.

#### 3단계: 난이도 증가
웨이브마다 적의 속도와 개수를 늘립니다.

## 심화 학습

- 적의 지능 개선
- 보너스 아이템
- 멀티플레이 지원
