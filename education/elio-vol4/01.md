# 카드 뒤집기 게임 만들기 1

## 학습 목표

| 목표 | 설명 |
|------|------|
| 스크래치 기초 | 스프라이트와 모양을 이용한 객체 생성 |
| 그래픽 디자인 | 벡터 모드에서 카드 모양 그리기 |
| 크기 계산 | 무대 크기에 맞춘 카드 배치 계산 |
| 복사와 붙여넣기 | 기존 모양을 복사하여 새로운 객체 생성 |

## 학습 내용

### 1. 프로젝트 소개
18장의 카드가 있는 뒤집기 게임을 만들어봅니다. 카드를 클릭하면 뒤집어지고, 같은 그림이 그려진 카드를 찾아서 짝을 맞추는 게임입니다.

### 2. 벡터 모드로 카드 그리기
벡터 모드로 그림을 그리면 크기를 쉽게 바꿀 수 있습니다. 사각형 도구를 사용하여 카드 모양을 만듭니다.

### 3. 카드 크기 계산
스크래치 무대의 크기는 가로 480, 세로 360입니다. 카드를 가로로 6개, 세로로 3개를 나열하려면 카드의 크기를 가로 80, 세로 120으로 정하면 적당합니다.

### 4. 모양 중심 설정
카드를 뒤집었을 때 회전이 부드러워지려면 그림의 중심을 잘 맞춰야 합니다. 모양 중심 설정하기 메뉴를 사용합니다.

### 5. 뒤집힌 카드 모양 만들기
뒤집었을 때 나오는 카드 모양을 따로 만듭니다. 기존 카드 모양을 복사해서 색깔을 바꾸고, 저장소에서 그림을 선택하여 카드에 넣습니다.
