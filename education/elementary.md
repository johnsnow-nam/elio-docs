# 🎨 초등 메이커 활동 — 빨대 프레임 + ELIO

> 빨대와 연결 클립으로 나만의 구조물을 만들고, ELIO로 움직이게 해보세요!  
> 코딩 없이 스마트폰 앱으로 즉시 제어 — **초등 3학년부터 가능합니다**.

---

## 교사를 위한 안내

### 수업 목표

- 빨대 프레임으로 3D 구조물 설계·제작 능력을 기른다
- 전기 모터·기어의 기본 원리를 이해한다
- ELIO 앱 조작을 통해 디지털 도구 사용에 친숙해진다

### 20분 사전 준비 체크리스트

- [ ] 빨대 (1인당 20개 이상 권장)
- [ ] 연결 클립·조인트 (키트 동봉)
- [ ] ELIO 보드 충전 확인
- [ ] 스마트폰 bletoy 앱 사전 설치
- [ ] 활동지 인쇄 (아래 60가지 카탈로그 중 선택)

---

## 빨대 프레임 소개

### 왜 빨대인가?

- 가볍고 안전 — 날카로운 모서리 없음
- 저렴하고 구하기 쉬움
- 다양한 길이·색상으로 시각적 분류 가능
- 연결 클립으로 3D 구조 구현 가능

### 기본 구조 원리

```
단일 빨대 → 뼈대
빨대 + 클립 → 관절
삼각형 구조 → 강한 뼈대
사각형 구조 → 유연한 프레임
```

---

## 60가지 활동 카탈로그

> ⚠ **[빨대 프레임 PPT 60가지 수령 후 각 활동 상세 내용 작성 예정]**  
> 현재 PPT 자료를 수령 대기 중입니다. 수령 후 아래 60가지 활동 카탈로그가 완성됩니다.

### 카탈로그 구조 (예시)

각 활동은 다음 형식으로 제공됩니다:

```
[활동 번호] 활동 이름
━━━━━━━━━━━━━━━━
난이도: ★☆☆ (쉬움) / ★★☆ (보통) / ★★★ (도전)
소요 시간: 30분 / 45분 / 60분
준비물: 빨대 n개, 클립 n개, ELIO 1개

[목표] 이 활동으로 무엇을 만드나요?
[핵심 원리] 어떤 과학·수학 개념이 담겨있나요?
[만들기 단계] 사진 + 단계별 설명
[ELIO 연결] 어디에 모터/서보를 달면 좋을까요?
[챌린지] 더 나아가기
```

### 활동 분류 (예시)

| 분류 | 활동 수 | 예시 |
|------|---------|------|
| 이동형 로봇 | 15개 | RC 카, 크롤러, 거미 로봇 |
| 팔·집게 | 12개 | 로봇 팔, 집게 크레인 |
| 날개·프로펠러 | 10개 | 선풍기, 헬리콥터 날개 |
| 구조물 | 13개 | 탑, 다리, 돔 |
| 예술·창작 | 10개 | 드로잉 로봇, 음악 기계 |

---

## 추천 첫 번째 활동 — RC 카 만들기

준비물: 빨대 12개, 클립 8개, ELIO 1개, 바퀴(키트 포함)

**단계:**

1. 빨대 4개로 사각형 차체 뼈대 만들기
2. 차체 앞뒤에 클립으로 바퀴 축 고정
3. DC 모터 → DC1 포트 연결
4. ELIO 보드 차체 중앙에 양면테이프로 고정
5. bletoy 앱 연결 → 조이스틱으로 주행!

## 나이별 권장 활동

| 학년 | 권장 난이도 | 추천 활동 |
|------|-------------|-----------|
| 3~4학년 | ★☆☆ | RC 카, 간단한 집게 |
| 5~6학년 | ★★☆ | 로봇 팔, 프로펠러 구조물 |
| 심화 (6학년+) | ★★★ | 자율 주행, 다관절 구조물 |

## 수업 흐름 (45분 기준)

| 시간 | 활동 |
|------|------|
| 0~5분 | 도입: 오늘 만들 것 소개 |
| 5~15분 | 빨대 프레임 구조물 제작 |

| 25~40분 | 챌린지 미션 |
| 40~45분 | 발표·공유 |
