# 강 5: 엘리오 앱 사용방법 (DC모터)

![ELIO 보드 사진](/elio-docs/assets/images/education/youtube-elio/elio-board.jpeg)

## 학습목표

| #   | 목표                                       |
| --- | ---------------------------------------- |
| 1   | DC 모터를 DC1/DC2에 연결하고 앱에서 포트를 선택할 수 있습니다. |
| 2   | 상하/좌우 컨트롤러로 모터 2개를 제어할 수 있습니다.           |
| 3   | 모터 방향이 반대일 때 “출력반전”으로 해결할 수 있습니다.        |

---

## 1. 기본 개념: DC1(왼쪽) / DC2(오른쪽)

슬라이드 기준 안내:

- 엘리오보드 **왼쪽 소켓 = DC1**
- 엘리오보드 **오른쪽 소켓 = DC2**

---

## 2. 상하 컨트롤러로 전/후진

1. 상하 컨트롤러를 화면에 드래그합니다.
2. DC모터 타겟을 컨트롤러 위에 올려놓습니다.
3. 모터 연결 위치(DC1 또는 DC2)를 선택합니다.
4. 속성에서 완료합니다.  
   - 모터가 반대로 돌면 **출력반전**을 켭니다.
5. 모터 2개를 쓰려면 동일 과정을 한 번 더 반복합니다.
6. 테스트로 확인합니다.

---

## 3. 좌우 컨트롤러로 회전(좌/우회전)

- 좌우 컨트롤러는 좌/우 드래그에 따라 **좌측/우측 모터의 정·역회전 조합**으로 회전 동작을 만듭니다.
- 회전 방향이 기대와 다르면:
  - 방법 1) 모터 케이블을 보드에 반대로 연결
  - 방법 2) 속성에서 **출력반전** 사용
