# 🎥 ELIO 유튜브 강좌

> **대상**: ELIO 처음 사용자(교사·학생·메이커) | **구성**: 21강 | **원본**: “유튜브_엘리오 강좌 교안.pptx” (한동효)

![ELIO 보드 사진](/elio-docs/assets/images/education/youtube-elio/elio-board.jpeg)

이 강좌는 **보드 연결(전원/LED/모터)** → **ELIO 앱(bletoy)로 즉시 제어** → **Blockly 블록 코딩(LED/모터/변수/함수/센서)** 순서로 학습합니다.

## 준비물

| 필수 | 선택 |
|------|------|
| ELIO 보드(미니보드 또는 블록보드) | 서보모터, 초음파센서(SR04), IR 센서(라인 센서) |
| 전원(건전지/배터리팩) | 점퍼와이어, 브레드보드, 탈피형 커넥터 |
| 스마트폰(bletoy 앱) | DC 모터 추가(모터드라이브), 레고/과학교구 부품 |

---

## 학습 흐름

```
[1-2] 배선/전원 기초           → 보드별 전원·포트 이해
[3-6] 앱으로 즉시 제어          → LED/DC/서보 연결과 조종기 만들기
[7-12] Blockly 코딩             → LED/변수/모터/함수로 로직 만들기
[13-16] 센서                    → IR/초음파로 입력값 활용
[17-21] 확장 아이디어           → 더 많은 모터·서보/레고/장난감 응용
```
