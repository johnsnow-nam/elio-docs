# 강 4: 엘리오 앱 사용방법 (LED2)

![ELIO 보드 사진](/elio-docs/assets/images/education/youtube-elio/elio-board.jpeg)

## 학습목표

| # | 목표 |
|---|------|
| 1 | 기존 모델을 편집 모드로 열 수 있습니다. |
| 2 | 버튼을 추가하고 두 번째 LED(IO2)를 제어할 수 있습니다. |
| 3 | LED 연결 포트(IO1~IO4)를 바꿔 설정할 수 있습니다. |

---

## 1. 편집 화면 열기

- 모델 목록에서 편집할 항목을 **왼쪽으로 드래그**합니다.
- **편집**을 선택합니다.

---

## 2. 버튼 추가 + LED 타겟 연결

1. 버튼 컨트롤러를 하나 더 추가합니다.
2. LED 타겟을 **두 번째 버튼** 위에 올려놓습니다.
3. LED가 연결된 위치로 **IO2**를 선택합니다.
4. 기본 출력(밝기)을 **90**으로 설정하고 완료합니다.
5. **테스트**로 동작 확인합니다.

---

## 3. 포트 변경 예시 (IO3로 바꾸기)

LED를 IO3로 옮겼다면 설정에서 **IO3**를 선택하면 됩니다.
