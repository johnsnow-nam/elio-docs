# 강 8: Blockly 사용방법 (LED + 음성)

## 학습목표

| # | 목표 |
|---|------|
| 1 | 텍스트 메시지를 화면에 출력할 수 있습니다. |
| 2 | 음성 인식(문자열) 조건으로 LED를 제어할 수 있습니다. |
| 3 | 띄어쓰기 차이가 조건에 영향을 준다는 점을 이해합니다. |

---

## 1. 메시지 + LED 제어 실습

슬라이드 기반 과제:

1. “빨간불이 켜져요” 메시지 출력 + 빨간 LED를 밝기 80으로 켜기
2. “빨간불이 켜져요” → 1초 후 끄기 → “녹색불이 켜져요” → 1초 후 끄기

---

## 2. 음성으로 켜고 끄기

슬라이드 기반 과제:

- “불 켜” 음성으로 LED 켜기, “불 꺼” 음성으로 LED 끄기
- “불 켜” 음성으로 LED 켜기, “꺼 주세요” 음성으로 LED 끄기

**주의(중요)**: 음성 문자열은 **띄어쓰기**까지 정확히 맞아야 합니다.

- `불켜` (X) → `불 켜` (O)
- `꺼주세요` (X) → `꺼 주세요` (O)
