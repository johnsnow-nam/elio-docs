# 🚗 미래 친환경 전기자동차 만들기

> **교과**: 기술·가정 | **대상**: 중학교 3학년 | **형태**: 2022학년도 1학기 수행평가  
> **주제**: 앞으로 우리가 이용하게 될 **미래 친환경 전기자동차**를 디자인하고 ELIO로 구현하기

---

## 가. 수행평가 개요

| 항목 | 내용 |
|------|------|
| **팀 구성** | 3인 1모둠, 1작품 |
| **배점** | 25점 = 개인별 활동지 10점 + 모둠 활동 15점 |
| **진행 방식** | 개인 활동지 작성 → 팀 협의 → 제작할 자동차 1작품 선정 → 주어진 재료로 제작 → 미션 수행 |
| **바퀴 제작** | 앞 또는 뒷바퀴 1세트는 **팀별 아이디어 회의를 거쳐 창의적으로 직접 제작** |
| **꾸미기 재료** | 개인 용품 사용 가능 (마카, 색종이 등) |

---

## 나. 준비물

### 교사 준비 재료

| 재료 | 규격/수량 |
|------|----------|
| ELIO 보드 | 팀당 1개 |
| DC 모터 | 2개 (바퀴+모터 세트) |
| 컬러 마카 | — |
| 골판지 | A3 크기 3장 |
| 30cm 자 | — |
| 칼, 가위 | — |
| 글루건 | 교사 전용 (학생 사용 제한) |
| 빨대 | — |
| **벨크로** | 모터 고정용 (글루건 대체) |

### 학생 준비 물품

- 스마트폰 (팀별 1대만 허용)
- 뒷바퀴 제작 재료 (팀별 자유 선택)

## 다. 조립 절차

![6단계 조립 사진 — ①부품확인 ②벨크로로 모터 고정(글루건X) ③골판지에 모터 장착 ④볼캐스터 부착 ⑤배선 연결 ⑥ELIO 보드 탑재](/elio-docs/assets/images/education/future-ev-car/04-assembly.jpg)

### 6단계 조립 순서

| 단계 | 내용 | 주의사항 |
|------|------|---------|
| ① | 부품 확인 (ELIO, 모터×2, 바퀴×2, 배터리, 볼캐스터) | — |
| ② | 모터에 바퀴 결합 | — |
| ③ | 골판지 차체에 모터 장착 | **벨크로 사용 / 글루건 사용 금지** |
| ④ | 골판지 반대면에 볼캐스터(앞바퀴) 부착 | — |
| ⑤ | DC-1, DC-2 포트에 모터 배선 연결 | +/- 극성 확인 |
| ⑥ | ELIO 보드 탑재 후 배터리 연결 | 보드가 움직이지 않도록 고정 |

> ⚠ **글루건은 교사만 사용**. 학생 사용 금지. 모터 고정은 반드시 **벨크로** 사용.

앱 연결 및 조종 방법은 [빠른 시작 가이드](/elio-docs/quickstart/)를 참고하세요.

## 마. 개인 활동지 — IDEA 노트

> **배점**: 10점 | **개인별 작성 후 팀 협의에 활용**

### IDEA 노트 1 — 문제 발견·해결 설계

| 항목 | 작성 내용 |
|------|----------|
| 현재 디젤·가솔린 자동차의 문제점 3가지 이상 | (학생 작성) |
| 위 문제점을 어떻게 개선할지 구체적으로 | (학생 작성) |
| 새로운 바퀴 제작 방법 (재료·도구) | (학생 작성) |
| 자율주행 자동차 일반화 시 발생할 사회적 문제점 | (학생 작성) |

### IDEA 노트 1 — 프리핸드 스케치 (구상도)

- 등각투상도 또는 사투상도로 자동차 측면 그리기
- 추천 검색 키워드: `자동차 도면`, `자동차 모형`, `자동차 도안`, `자동차 스케치`, `페이퍼 카`

### 부품도 그리기

| 안내사항 | 내용 |
|---------|------|
| 기준 크기 | 주어진 재료(골판지) = 420mm × 320mm |
| 부품 배치 | 부품별 모양과 치수를 계산해 사각형 안에 배치 |
| 작성 도구 | 자로 반듯하게 / 연필과 지우개 사용 |

### IDEA 노트 2 — 제작 후 성찰 (개인)

| 항목 | 내용 |
|------|------|
| 자동차 모형 제작 소감 | 표현하고 싶었던 부분, 아쉬웠던 부분, 좋았던 부분 |
| 하이브리드 / 전기 / 수소 자동차의 차이점 | (개념 정리) |
| 팀에서 자신이 주도적으로 한 역할 | (자기 평가) |
| 동료 평가 | 팀명·평가 기입 |

## 바. 모둠 활동지 — IDEA 노트 (팀 공동 작성)

> **배점**: 15점 | **팀원 협의 후 공동 작성**

| 항목 | 내용 |
|------|------|
| 팀에서 제작한 수송장치의 특징 | 화석연료 자동차보다 미래에 적합한 이유 포함 |
| 제작 과정에서 가장 어려웠던 점과 개선 노력 | 구체적으로 서술 |
| 더 나은 미션 결과를 위해 개선하고 싶은 부분 | 이유와 방법 포함 |
| 자율주행 자동차 일반화 시 사회적 문제점 | 3가지 이상 |
