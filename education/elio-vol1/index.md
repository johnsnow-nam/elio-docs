# 🤖 ELIO 1권 — 토이스토리

> **대상**: 초등 고학년 · 중학생 | **구성**: 8단원+ | **원본**: 2019년 ELIO 공식 교재

ELIO와 함께 폐기된 장난감을 되살리는 영화 '토이스토리' 프로젝트입니다. ELIO 보드와 스마트폰 앱으로 다양한 장난감을 제어하는 방법을 배웁니다.

---

## 단원 목록

| 단원 | 제목 | 핵심 학습 |
|:----:|------|----------|
| [1](/elio-docs/education/elio-vol1/01/) | 처음 만나는 엘리오 | ELIO 소개, 포트 구성, 앱 설치, BLE 연결 |
| [2](/elio-docs/education/elio-vol1/02/) | 깜빡이는 LED | LED 극성, IO 포트 제어, 밝기 조절 |
| [3](/elio-docs/education/elio-vol1/03/) | DC모터와 서보모터 | 모터 원리, 출력 반전, 서보 연결·제어 |
| [4](/elio-docs/education/elio-vol1/04/) | LED를 이용한 조명 | 앱에서 LED 제어, 색상 설정, ON/OFF 제어 |
| [5](/elio-docs/education/elio-vol1/05/) | 모터의 원리와 제어 | DC 모터 방향 제어, 속도 조절, -100~100 값 설정 |
| [6](/elio-docs/education/elio-vol1/06/) | 멋진 탱크를 만들어요 | 탱크 조립, DC 모터 2개 제어, 움직임 제어 |
| [7](/elio-docs/education/elio-vol1/07/) | RC카에게 날개를 달아요 | RC카 분해·개선, DC/서보 모터 제어, 앱 설정 |
| [8](/elio-docs/education/elio-vol1/08/) | 거미로봇을 움직여요 | 거미로봇 원리, 모터 1개/2개 제어, 연결 방법 |

---

## 학습 흐름

```
[단원 1-3]   기초 이해              → ELIO 기본, 포트, 전기·모터 원리
[단원 4-6]   기본 제어              → LED, 모터 제어, 탱크 조립
[단원 7-8]   응용 제어              → RC카, 거미로봇 제어 및 응용
```

---

## 준비물

| 필수 | 선택 |
|------|------|
| ELIO 보드 | 외부 안테나 (원거리 제어 시) |
| 폐기 장난감 (RC카, 거미로봇 등) | 추가 LED, 서보모터 |
| 스마트폰 (iOS/Android) | 추가 DC 모터 |
| [bletoy 앱](/elio-docs/quickstart/) | 배터리·배선 추가 세트 |
