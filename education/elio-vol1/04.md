# 단원 04: LED를 이용한 조명

## 1. LED란?

### LED의 기본

LED(Light Emitting Diode)는 **전기를 받으면 빛을 내는** 반도체 부품입니다.

- **색상 다양**: 빨강, 초록, 파랑, 노랑, 흰색 등
- **저전력**: 배터리를 오래 사용할 수 있습니다
- **극성 중요**: DC모터처럼 +/-가 정해져 있습니다

![이미지](/elio-docs/assets/images/education/elio-vol1/image107.emf)

### LED의 구조

LED는 두 개의 다리를 가지고 있습니다:

| 다리 | 의미 | 표시 |
|------|------|------|
| **긴 다리** | +극 (양극) | Anode |
| **짧은 다리** | -극 (음극) | Cathode |

![이미지](/elio-docs/assets/images/education/elio-vol1/image106.emf)

## 2. LED 극성 연결하기

### ELIO I/O 포트 이해

ELIO 후면의 **I/O 1~4** 포트를 사용하여 LED를 연결합니다.

| 포트 | 설명 |
|------|------|
| I/O 1 ~ I/O 4 | LED를 최대 4개까지 동시에 연결할 수 있습니다 |

### LED 연결 방법

1. LED의 **긴 다리(+극)**를 ELIO I/O 포트의 **빨강(+)** 선에 연결
2. LED의 **짧은 다리(-극)**를 ELIO I/O 포트의 **검정(-)** 선에 연결

**주의:** LED의 극성이 반대면 **불이 켜지지 않습니다**

![이미지](/elio-docs/assets/images/education/elio-vol1/image105.emf)

### 저항 사용 (선택)

LED가 너무 밝거나 전력 소비가 큰 경우, **저항(330Ω~1kΩ)**을 LED의 +극과 I/O 포트 사이에 연결할 수 있습니다.

![이미지](/elio-docs/assets/images/education/elio-vol1/image104.png)

---

## 3. ELIO 앱으로 LED 제어하기

### LED 제어 모델 만들기

1. ELIO 앱에서 **새 모델** 생성
2. 컨트롤러 추가 (버튼, 슬라이더 등)
3. **LED IO 타겟** 추가
4. 컨트롤러와 LED 연결

![이미지](/elio-docs/assets/images/education/elio-vol1/image103.emf)

### LED ON/OFF 제어

**버튼 컨트롤러로 LED 제어:**

1. 모델에 **버튼** 추가
2. 버튼에 **LED 타겟** 연결
3. 버튼을 누르면 LED가 켜지고, 다시 누르면 꺼집니다

![이미지](/elio-docs/assets/images/education/elio-vol1/image102.png)

### LED 밝기 조절

**슬라이더로 LED 밝기 제어:**

1. 모델에 **슬라이더** 추가
2. 슬라이더에 **LED 타겟** 연결
3. 슬라이더를 움직이면 LED의 밝기가 **0~100%** 사이에서 조절됩니다

![이미지](/elio-docs/assets/images/education/elio-vol1/image101.emf)

---

## 4. LED 깜빡임 효과 만들기

### 깜빡임 패턴

ELIO 앱의 고급 기능을 사용하여 LED를 깜빡이게 할 수 있습니다:

| 패턴 | 설명 |
|------|------|
| **점멸** | 일정 간격으로 켜기/끄기 반복 |
| **페이드 인** | 서서히 밝아지기 |
| **페이드 아웃** | 서서히 어두워지기 |
| **호흡** | 점점 밝아졌다 점점 어두워지기 (반복) |

![이미지](/elio-docs/assets/images/education/elio-vol1/image100.png)

---

## 5. 다중 LED 제어

### 여러 개의 LED 제어

ELIO는 **I/O 포트 4개**이므로 **최대 4개의 LED**를 동시에 제어할 수 있습니다:

1. LED 1 → I/O 1
2. LED 2 → I/O 2
3. LED 3 → I/O 3
4. LED 4 → I/O 4

![이미지](/elio-docs/assets/images/education/elio-vol1/image10.png)

### 무지개 조명 만들기

여러 색상의 LED를 각각 다른 패턴으로 제어하여 **무지개 조명 효과**를 만들 수 있습니다.

![이미지](/elio-docs/assets/images/education/elio-vol1/image1.png)
