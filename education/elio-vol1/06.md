# 단원 06: 멋진 탱크를 만들어요

## 학습목표

| # | 목표 |
|---|------|
| 1 | 탱크의 구조와 작동 방식을 이해할 수 있다 |
| 2 | DC 모터 2개로 탱크를 제어할 수 있다 |
| 3 | 앱에서 탱크 모델을 만들고 조종할 수 있다 |

---

## 1. 탱크 로봇의 특징

### 탱크의 구조

탱크는 **두 개의 바퀴(또는 궤도)**가 독립적으로 움직이는 형태의 로봇입니다:

- **왼쪽 바퀴**: DC 모터 1로 제어
- **오른쪽 바퀴**: DC 모터 2로 제어
- **캐스터**: 앞바퀴(회전 가능한 바퀴)로 균형 유지

![이미지](/elio-docs/assets/images/education/elio-vol1/image108.emf)

### 이동 방식

탱크는 양쪽 모터를 **다르게 제어**하여 다양한 움직임을 만듭니다:

| 모터 1 | 모터 2 | 결과 |
|:------:|:------:|------|
| 100 | 100 | 앞으로 직진 |
| -100 | -100 | 뒤로 후진 |
| 100 | -100 | 제자리 우회전 (시계방향) |
| -100 | 100 | 제자리 좌회전 (반시계방향) |
| 100 | 50 | 오른쪽으로 회전 이동 |
| 50 | 100 | 왼쪽으로 회전 이동 |

![이미지](/elio-docs/assets/images/education/elio-vol1/image107.emf)

---

## 2. 탱크 조립하기

### 준비물

| 부품 | 개수 | 설명 |
|------|:----:|------|
| ELIO 보드 | 1 | 제어 보드 |
| DC 모터 (TT모터) | 2 | 양쪽 바퀴 구동 |
| 바퀴 | 2 | 모터에 연결 |
| 캐스터 | 1 | 앞쪽 지지 바퀴 |
| 샤시(몸체) | 1 | 로봇 본체 |
| 배터리팩 | 1 | 전원 공급 (권장 8AA) |

![이미지](/elio-docs/assets/images/education/elio-vol1/image106.emf)

### 조립 순서

1. **모터를 샤시에 고정**: 양쪽 바퀴에 모터를 붙입니다
2. **모터에 바퀴 연결**: 모터 축에 바퀴를 끼웁니다
3. **캐스터 설치**: 샤시의 앞쪽에 캐스터를 붙입니다
4. **ELIO 보드 탑재**: 샤시 위에 ELIO 보드를 고정합니다
5. **모터와 ELIO 연결**: 모터 선을 ELIO의 DC-1, DC-2에 연결합니다
6. **배터리 연결**: 배터리팩을 ELIO의 배터리 포트에 연결합니다

![이미지](/elio-docs/assets/images/education/elio-vol1/image105.emf)

---

## 3. ELIO 앱에서 탱크 모델 만들기

### 탱크 모델 설정

1. ELIO 앱 실행
2. **새 모델** 생성 (이름: "탱크")
3. **십자 패드 (상/하/좌/우)** 컨트롤러 추가
4. **DC 모터 2개** 타겟 추가

![이미지](/elio-docs/assets/images/education/elio-vol1/image104.png)

### 컨트롤러와 모터 연결

**상/하 패드:**
- **상 (위쪽)**: 양쪽 모터 모두 100 → 앞으로 이동
- **하 (아래쪽)**: 양쪽 모터 모두 -100 → 뒤로 이동

**좌/우 패드:**
- **좌 (왼쪽)**: 모터 1 = 50, 모터 2 = 100 → 왼쪽으로 회전
- **우 (오른쪽)**: 모터 1 = 100, 모터 2 = 50 → 오른쪽으로 회전

![이미지](/elio-docs/assets/images/education/elio-vol1/image103.emf)

---

## 4. 탱크 테스트 주행

### 주행 전 확인

1. ELIO 전원이 켜져 있는지 확인 (파란 LED 점등)
2. 앱과 ELIO가 페어링되어 있는지 확인
3. 모터가 올바르게 회전하는지 확인

![이미지](/elio-docs/assets/images/education/elio-vol1/image102.png)

### 주행 테스트

1. 탱크를 바닥에 내려놓습니다
2. 앱에서 **십자 패드**를 조작합니다
3. 탱크가 의도한 방향으로 움직이는지 확인합니다

**만약 탱크가 이상하게 움직인다면:**
- 모터의 극성이 반대일 수 있습니다 (선을 바꿔서 다시 연결)
- 모터 축이 바퀴에 제대로 끼워져 있는지 확인합니다

![이미지](/elio-docs/assets/images/education/elio-vol1/image101.emf)

---

## 5. 탱크 성능 최적화

### 모터 밸런싱

양쪽 모터의 힘이 다르면 탱크가 한쪽으로 쏠릴 수 있습니다.

**해결 방법:**
- 약한 쪽 모터의 값을 조금 더 높게 설정합니다
- 예: 모터 1 = 100, 모터 2 = 105

### 배터리 관리

- **배터리가 약할 때**: 모터의 속도가 느려집니다
- **배터리 부족 시**: LED가 빨간색으로 점등합니다
- 정기적으로 배터리를 교체하세요

![이미지](/elio-docs/assets/images/education/elio-vol1/image100.png)

---

## 6. 탱크의 응용

### 추가 부품 장착

탱크 위에 다음 부품을 추가할 수 있습니다:

- **LED**: 앞쪽에 설치하여 조명 역할
- **서보 모터**: 팔이나 포탑처럼 회전하는 부품
- **센서**: 장애물 감지 (고급)

![이미지](/elio-docs/assets/images/education/elio-vol1/image10.png)

### 미션 및 게임

탱크를 이용한 다양한 활동:

- **장애물 피하기**: 코스를 정해서 탱크가 통과하는 시간 재기
- **물건 운반**: 탱크 위에 물건을 올려 목표지점까지 운반하기
- **춤추는 탱크**: 음악에 맞춰 탱크를 움직이기

![이미지](/elio-docs/assets/images/education/elio-vol1/image1.png)
