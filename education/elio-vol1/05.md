# 단원 05: 모터의 원리와 제어

## 학습목표

| # | 목표 |
|---|------|
| 1 | 모터의 속도와 방향 제어 원리를 이해할 수 있다 |
| 2 | -100~100 값으로 모터를 정밀하게 제어할 수 있다 |
| 3 | 앱의 변수 기능으로 동적 모터 제어를 할 수 있다 |

---

## 1. 모터 제어의 기본

### DC모터 제어 방식

ELIO에서 DC모터는 **-100~100의 범위**로 제어됩니다:

| 값 | 의미 | 모터 상태 |
|:--:|------|----------|
| **-100** | 최대 역방향 | 반대 방향으로 최고 속도 회전 |
| **-50** | 중간 역방향 | 반대 방향으로 중간 속도 회전 |
| **0** | 정지 | 모터 정지 |
| **50** | 중간 정방향 | 정상 방향으로 중간 속도 회전 |
| **100** | 최대 정방향 | 정상 방향으로 최고 속도 회전 |

> 📷 [이미지: -100~100 범위에서의 모터 속도 그래프]

### 속도와 전압의 관계

모터의 속도는 **인가된 전압의 크기**에 비례합니다:

- **높은 값 (±100)**: 높은 전압 → 빠른 회전
- **낮은 값 (±20)**: 낮은 전압 → 느린 회전

---

## 2. 앱에서 모터 제어하기

### 슬라이더로 모터 제어

**범위 선택 슬라이더:**

1. 모델에 **슬라이더 컨트롤러** 추가
2. 슬라이더 설정에서 **범위를 -100~100**으로 설정
3. **DC 모터 타겟** 연결
4. 슬라이더를 움직여 모터 속도와 방향을 제어합니다

> 📷 [이미지: 슬라이더로 DC모터 제어]

### 방향 선택 패드

**십자 패드 (좌/우 또는 상/하):**

1. **상/하 패드**: 전진/후진 제어
2. **좌/우 패드**: 회전 제어
3. 패드를 누르면 모터가 의도한 방향으로 회전합니다

> 📷 [이미지: ELIO 앱의 십자 패드 컨트롤]

---

## 3. 다중 모터 제어

### 두 개 이상의 모터 제어

ELIO는 **DC 모터 2개 (DC-1, DC-2)** 를 동시에 제어할 수 있습니다:

1. 모델에 두 개의 **DC 모터 타겟** 추가
   - DC 모터 1
   - DC 모터 2

2. 각각 다른 컨트롤러 또는 같은 컨트롤러에 연결

> 📷 [이미지: 두 개의 DC모터 제어 설정]

### 차동 구동 (탱크/로봇 움직임)

두 모터의 값을 다르게 설정하면 로봇이 회전합니다:

| 상황 | 모터 1 | 모터 2 | 결과 |
|------|:------:|:------:|------|
| 직진 | 100 | 100 | 앞으로 이동 |
| 좌회전 | 50 | 100 | 왼쪽으로 회전 |
| 우회전 | 100 | 50 | 오른쪽으로 회전 |
| 후진 | -100 | -100 | 뒤로 이동 |
| 제자리 회전 | 100 | -100 | 시계 방향 회전 |

> 📷 [이미지: 다양한 모터 조합에 따른 로봇 움직임]

## 4. 변수로 모터 동적 제어하기

### 변수(Variable) 개념

**변수**는 모터의 값을 저장하고 변경할 수 있는 저장소입니다.

**변수 생성:**

1. 앱 메뉴에서 **변수** 선택
2. **새 변수 생성** (예: "모터 속도")
3. 초기값 설정 (예: 0)

> 📷 [이미지: ELIO 앱에서 변수 생성]

### 변수로 모터 제어

1. **슬라이더**를 변수에 연결
2. **DC 모터**를 변수에 연결
3. 슬라이더를 움직이면 변수 값이 변경되고, 모터가 반응합니다

**장점:**
- 여러 부품을 하나의 변수로 제어 가능
- 코딩에서 변수값을 동적으로 변경 가능

> 📷 [이미지: 변수를 통한 모터 제어 흐름]

## 5. 모터 제어 예제

### 예제 1: 속도 조절 기어

슬라이더를 3단계로 나누어 속도를 조절합니다:

| 슬라이더 위치 | 모터값 | 속도 |
|:---:|:---:|------|
| 낮음 | 33 | 저속 |
| 중간 | 67 | 중속 |
| 높음 | 100 | 고속 |

> 📷 [이미지: 3단계 속도 조절 슬라이더]

### 예제 2: 단계별 회전

버튼을 여러 개 만들어 각각 다른 각도로 회전하게 합니다:

- **버튼 1**: 45도 회전 (값: 50)
- **버튼 2**: 90도 회전 (값: 100)
- **버튼 3**: 원위치 (값: 0)

> 📷 [이미지: 단계별 회전 버튼 설정]
