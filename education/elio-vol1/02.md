## 1. ELIO 보드 살펴보기

### 상단 인터페이스

ELIO 보드의 상단에는 다음과 같은 구성요소가 있습니다:

| 번호 | 이름 | 설명 |
|------|------|------|
| ① | 외부 스위치 | 장난감 내부에 내장 시 전원 스위치로 활용 |
| ② | 전원 버튼 | 1번 누름: 켜기 / 연속 2번: 끄기 / 길게: 초기화 |
| ③ | 상태 LED | 파란색 깜빡임: 미연결 / 파란색 점등: 연결됨 / 빨간색: 배터리 부족 |
| ④ | 외부 안테나 | 먼 거리 제어 시 안테나 연결 |

> 📷 [이미지: ELIO 보드 상단 구성도]

---

## 2. ELIO 포트 이해하기

### 전면 포트 (DC 모터 포트)

| 포트 | 용도 |
|------|------|
| 배터리 | DC 5V~9V 전원 공급 (권장 8AA 배터리팩) |
| DC-1 | DC 모터 1번 연결 |
| DC-2 | DC 모터 2번 연결 |

> 📷 [이미지: ELIO 전면 배터리·DC 포트 다이어그램]

### 후면 포트 (I/O, 서보 포트)

| 포트 | 설명 |
|------|------|
| **I/O 1~4** | LED 연결 (빨간=+극, 검은=-극). LED 4개 동시 연결 가능 |
| **전압포트 3V/5V** | 외부 부품에 3V 또는 5V 전압 공급 |
| **서보모터 S1/S2** | 갈색=-극 / 빨강=+5V / 노랑=신호(S1 또는 S2) |

> 📷 [이미지: ELIO 후면 I/O·서보모터 포트 다이어그램]

**ELIO 한 보드로 동시 제어 가능:**
- DC 모터 2개
- 서보모터 2개
- LED 4개

---

## 3. ELIO 사용 준비하기

### 전원 연결

1. ELIO 배터리 포트에 **DC 5~9V 전원**을 연결합니다 (권장: 8AA 배터리팩)
2. 연결 후 전원 버튼을 1번 눌러 부팅합니다
3. LED가 **파란색으로 깜빡이면** 정상입니다 (아직 앱과 미연결 상태)

> 📷 [이미지: ELIO 전원 연결 및 상태 LED]

---

## 4. ELIO 앱 설치 및 기본 모델 만들기

### 앱 설치

1. 스마트폰 앱 검색창에서 **"엘리오"** 또는 **"bletoy"** 검색
2. **ELIO - DIY 블루투스 콘트롤러** 앱을 설치합니다
3. 앱을 실행하면 **토이 모델 선택** 화면이 나타납니다

> 📷 [이미지: Google Play/App Store의 ELIO 앱]

### C.A.T. 개념 (앱 핵심 구조)

ELIO 앱은 **C.A.T.** (고양이 🐱) 구조로 작동합니다:

| 역할 | 설명 | 예시 |
|------|------|------|
| **C**ontroller | 화면에서 사용자가 조종하는 UI | 상하 패드, 좌우 패드, 자유이동 패드, 버튼 |
| **A**ctor | 컨트롤러가 가진 역할 분담 | Left-Right 액터, Up-Down 액터 |
| **T**arget | 실제 출력 부품 | DC 모터, 서보모터, LED(IO) |

> 📷 [이미지: C.A.T. 개념도 — 컨트롤러→액터→타겟 흐름]

### 모델 만들기 순서

1. 메뉴 **+** 버튼 → 모델 이름 입력 (예: "나만의 장난감")
2. 도구 상자에서 원하는 **컨트롤러**를 1초 눌러 화면에 드래그
3. 도구 상자에서 **타겟**(모터·LED)을 컨트롤러 위에 올려 연결
4. **완료** 버튼으로 저장

> 📷 [이미지: ELIO 앱에서 모델 만드는 과정]

---

## 5. ELIO와 앱 연결하기

### 페어링 절차

1. ELIO 전원 버튼을 한 번 누릅니다
2. **파란 LED 깜빡임** 확인 (아직 연결 안 된 상태)
3. 앱 실행 → **페어링 버튼** 누르기
4. 목록에서 **ELIO_XXXX** 선택
5. 파란 LED가 **깜빡임을 멈추고 점등** → 연결 성공

> 📷 [이미지: ELIO 블루투스 페어링 화면]

**연결 확인:**
- 앱 하단 상태바(DC / SERVO / IO 수치)가 표시되면 정상 연결입니다
