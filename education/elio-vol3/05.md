# 단원 5: 스네이크 게임 만들기

## 학습 목표

| 항목 | 내용 |
|------|------|
| 주제 | 클래식 게임 개발 |
| 난이도 | 중급 |
| 소요시간 | 2시간 |
| 학습 내용 | 좌표 관리, 충돌 감지, 게임 상태 |

## 개요

고전적인 스네이크 게임을 스크래치로 구현하는 프로젝트입니다. 게임의 핵심 메커니즘을 배우고 다양한 개선을 시도합니다.

## 주요 학습 내용

### 준비물
- ELIO 로봇
- 스크래치 환경
- 컨트롤러 또는 키보드

### 기본 개념
- 2D 좌표 시스템
- 리스트를 통한 뱀의 몸 관리
- 충돌 감지 알고리즘
- 게임 상태 관리

### 코딩 요소
- 다중 리스트 관리
- 반복문과 조건 분기
- `클론` 또는 `스프라이트` 활용
- 점수 시스템

## 📷 [이미지: 스네이크 게임 화면]

## 학습 단계

#### 1단계: 기본 뱀 만들기
리스트를 사용하여 뱀을 표현합니다.

#### 2단계: 먹이와 충돌 로직
먹이를 생성하고 충돌을 감지합니다.

#### 3단계: 게임 완성
속도 증가, 점수 표시 등을 추가합니다.

## 심화 학습

- 난이도 선택
- 최고 점수 기록
- 사운드 효과 추가
