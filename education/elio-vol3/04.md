# 단원 4: 재미있는 말놀이를 해요

## 학습 목표

| 항목 | 내용 |
|------|------|
| 주제 | 말놀이 게임 제작 |
| 난이도 | 중급 |
| 소요시간 | 1.5시간 |
| 학습 내용 | 텍스트 처리, 문자열 함수 |

## 개요

말의 특성을 이용한 다양한 놀이를 프로그램으로 구현하는 프로젝트입니다. 텍스트 조작과 문자열 함수를 활용합니다.

## 주요 학습 내용

### 준비물
- ELIO 로봇
- 스크래치 환경
- 스피커 (선택)

### 기본 개념
- 문자열 연결 및 반복
- 거꾸로 읽기, 첫 글자 추출
- 음성 합성 활용

### 코딩 요소
- `문자열 조합` 블록
- `문자열 길이` 함수
- `문자 추출` 함수
- `말하기` 블록

![이미지](/elio-docs/assets/images/education/elio-vol3/ch01-slide1.jpg)

## 학습 단계

#### 1단계: 기본 말놀이 구현
단순한 문자열 조작 놀이를 구현합니다.

#### 2단계: 여러 종류의 놀이 추가
거꾸로 읽기, 초성 추출 등 다양한 놀이를 추가합니다.

#### 3단계: 음성 피드백 추가
음성으로 결과를 전달합니다.

## 심화 학습

- 단어 게임 응용
- 언어 처리 고급 기법
- 점수 시스템 연동
