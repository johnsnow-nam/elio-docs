# 단원 7: 라인센서로 게임 만들기

## 학습 목표

| 항목 | 내용 |
|------|------|
| 주제 | 센서 기반 게임 |
| 난이도 | 중급 |
| 소요시간 | 1.5시간 |
| 학습 내용 | 실시간 입력 처리, 게임 로직 |

## 개요

라인센서의 입력값을 이용하여 대화형 게임을 만드는 프로젝트입니다. 센서 감지와 게임 진행을 연결합니다.

## 주요 학습 내용

### 준비물
- ELIO 로봇
- 라인센서
- 스크래치 환경
- 검은색 테이프로 만든 게임 맵

### 기본 개념
- 실시간 센서 모니터링
- 상태 기계(State Machine) 구현
- 점수 계산 및 관리
- 게임 종료 조건

### 코딩 요소
- 무한 루프 내 센서 체크
- 다중 조건 분기
- 리스트로 상태 저장
- 게임 오버 로직

## 📷 [이미지: 센서 기반 게임 맵]

## 학습 단계

#### 1단계: 간단한 반응 게임
센서가 반응할 때마다 점수를 얻습니다.

#### 2단계: 시간 제한 추가
정해진 시간 안에 최대한 많은 점수를 얻습니다.

#### 3단계: 게임 난이도 조절
점수에 따라 게임 속도를 증가시킵니다.

## 심화 학습

- 리더보드 기능
- 다단계 레벨 시스템
- 사운드와 시각 효과
