# 단원 6: 라인센서를 알아봐요

## 학습 목표

| 항목 | 내용 |
|------|------|
| 주제 | 라인센서 기본 |
| 난이도 | 초급-중급 |
| 소요시간 | 1시간 |
| 학습 내용 | 센서 이해, 값 읽기, 기본 제어 |

## 개요

ELIO의 라인센서(적외선 센서)의 원리와 사용법을 배우는 프로젝트입니다. 센서 값을 읽고 기본 제어를 시도합니다.

## 주요 학습 내용

### 준비물
- ELIO 로봇
- 라인센서 모듈
- 스크래치 환경
- 검은색 테이프 (테스트 환경)

### 기본 개념
- 적외선 센서의 작동 원리
- 아날로그 신호 읽기
- 값의 범위와 해석
- 센서 보정

### 코딩 요소
- `센서 값 읽기` 블록
- 조건문으로 값 비교
- 변수에 센서 값 저장
- 디버깅 (값 표시)

## 📷 [이미지: 라인센서와 테스트 환경]

## 학습 단계

#### 1단계: 센서 연결 및 값 확인
라인센서를 연결하고 읽은 값을 확인합니다.

#### 2단계: 센서 보정
흰색과 검은색에서의 센서 값을 기록합니다.

#### 3단계: 임계값 설정
센서 값을 해석하기 위한 기준값을 설정합니다.

## 심화 학습

- 여러 센서의 동시 읽기
- 노이즈 필터링
- 선형보간을 통한 정확도 향상
