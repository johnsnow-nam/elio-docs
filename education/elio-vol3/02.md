# 단원 2: 멋진 무늬 만들어요

## 학습 목표

| 항목 | 내용 |
|------|------|
| 주제 | LED 무늬 만들기 |
| 난이도 | 초급-중급 |
| 소요시간 | 1-2시간 |
| 학습 내용 | LED 다중 제어, 패턴 프로그래밍 |

## 개요

여러 개의 LED를 연결하여 다양한 패턴을 만드는 프로젝트입니다. 반복문과 변수를 활용하여 창의적인 무늬를 구현합니다.

## 주요 학습 내용

### 준비물
- ELIO 로봇
- LED 여러 개
- 포트 연결 케이블

### 기본 개념
- 여러 포트의 동시 제어
- 반복문을 통한 패턴 생성
- 시간 지연 함수 활용

### 코딩 요소
- 다중 `포트 제어` 블록
- `반복` 및 `대기` 블록
- `변수` 활용

![이미지](/elio-docs/assets/images/education/elio-vol3/ch01-slide1.jpg)

## 학습 단계

#### 1단계: LED 여러 개 연결
여러 포트에 LED를 연결합니다.

#### 2단계: 패턴 함수 만들기
순차적으로 LED를 제어하는 함수를 작성합니다.

#### 3단계: 다양한 패턴 구현
반복과 지연을 조합하여 아름다운 패턴을 만듭니다.

## 심화 학습

- 무늬의 속도 조절
- 복잡한 다중 패턴
- 음악과의 연동
