# 단원 8: 라인 트레이서를 만들어요

## 학습 목표

| 항목 | 내용 |
|------|------|
| 주제 | 자동 추적 로봇 |
| 난이도 | 중급-고급 |
| 소요시간 | 2시간 |
| 학습 내용 | PID 제어, 모터 제어, 피드백 루프 |

## 개요

라인센서를 이용하여 검은 선을 자동으로 따라가는 라인 트레이서를 만드는 프로젝트입니다. 자율주행의 기초 원리를 배웁니다.

## 주요 학습 내용

### 준비물
- ELIO 로봇
- 라인센서 (좌우 2개)
- DC 모터 2개
- 스크래치 환경
- 검은색 테이프로 만든 경로

### 기본 개념
- 피드백 제어 루프
- 편차 계산 및 보정
- 모터 속도 조정
- PID 제어의 기초

### 코딩 요소
- 다중 센서 동시 읽기
- 차등 제어 (Differential Drive)
- 루프를 통한 지속적 조정
- 변수를 통한 파라미터 조정

![이미지](/elio-docs/assets/images/education/elio-vol3/ch01-slide1.jpg)

## 학습 단계

#### 1단계: 센서 값 비교
좌우 센서 값을 비교하여 방향을 판단합니다.

#### 2단계: 간단한 회피 로직
선에서 벗어났을 때 방향을 조정합니다.

#### 3단계: 부드러운 주행
속도와 방향을 미세하게 조정하여 부드럽게 따라갑니다.

## 심화 학습

- 곡선 경로 고속 주행
- 교차로 감지 및 대응
- PID 파라미터 최적화
