# 단원 1: 신호등 만들어요

## 학습 목표

| 항목 | 내용 |
|------|------|
| 주제 | 신호등 만들기 |
| 난이도 | 초급 |
| 소요시간 | 1-2시간 |
| 학습 내용 | LED 제어, 기본 스크래치 프로그래밍 |

## 개요

엘리오와 스크래치를 이용하여 신호등을 만드는 프로젝트입니다. LED를 포트에 연결하고 색깔을 제어하는 방법을 배웁니다.

## 주요 학습 내용

### 준비물
- ELIO 로봇
- LED (빨강, 노랑, 초록)
- 포트 연결 케이블

### 기본 개념
- 함수를 활용한 코드 작성
- 포트에 맞는 LED 연결
- 색깔 변화 타이밍 제어

### 코딩 요소
- `반복하기` 블록
- `변수` 설정
- `조건 분기`
- `함수 만들기`

![신호등 만들기 프로젝트](/elio-docs/assets/images/education/elio-vol3/ch01-slide1.jpg)

## 학습 단계

#### 1단계: 준비하기
포트에 맞게 LED를 연결합니다.

#### 2단계: 함수 만들기
신호등을 제어하는 함수를 만들어서 코딩합니다.

#### 3단계: 신호등 작동시키기
반복문을 이용하여 신호등이 계속 작동하도록 합니다.

## 심화 학습

- 신호등 타이밍 조정
- 복합 신호 패턴 구현
- 버튼 입력으로 제어하기
