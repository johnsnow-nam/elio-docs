# 단원 3: 리스트를 사용하여 퀴즈 게임을 만들어요

## 학습 목표

| 항목 | 내용 |
|------|------|
| 주제 | 퀴즈 게임 개발 |
| 난이도 | 중급 |
| 소요시간 | 2시간 |
| 학습 내용 | 리스트 구조, 조건 분기, 게임 로직 |

## 개요

리스트 자료구조를 활용하여 퀴즈 게임을 만드는 프로젝트입니다. 문제와 답을 저장하고 사용자 입력을 확인하는 방식을 배웁니다.

## 주요 학습 내용

### 준비물
- ELIO 로봇
- 스크래치 개발 환경
- 버튼 또는 센서

### 기본 개념
- 리스트(배열) 생성 및 관리
- 인덱스를 통한 요소 접근
- 조건 비교 및 점수 계산

### 코딩 요소
- `리스트 생성` 및 `항목 추가`
- `리스트에서 가져오기` 블록
- `만약...이면` 조건문
- 변수를 통한 점수 관리

## 📷 [이미지: 퀴즈 게임 인터페이스]

## 학습 단계

#### 1단계: 리스트 만들기
퀴즈 문제와 정답을 리스트로 생성합니다.

#### 2단계: 게임 로직 구성
질문 출력, 답변 입력, 정답 확인 로직을 구현합니다.

#### 3단계: 점수 시스템 추가
정답 개수를 세고 최종 점수를 표시합니다.

## 심화 학습

- 난이도별 문제 분류
- 타이머 추가
- 고급 점수 계산
