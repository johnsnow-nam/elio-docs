# 🚗 미래 친환경 전기자동차 만들기

> **교과**: 중학교 기술·가정 (3학년 1학기 권장)  
> **수업 형태**: 모둠 활동 (3인 1모둠)  
> **총 수업 시간**: **4차시** (기본) / 17차시 (자유학기 연계 확장)  
> **평가**: 25점 — 개인 활동지 10점 + 모둠 활동 15점

![수행평가 주제 — 미래 친환경 전기자동차](/elio-docs/assets/downloads/edu/future-transport-01.png)

---

## 교사를 위한 안내

### 수업 목표

- 미래 수송기기의 개념을 이해하고 친환경 전기자동차를 창의적으로 설계한다
- ELIO와 DC 모터를 연결해 스마트폰으로 자동차를 제어하는 원리를 파악한다
- 모둠 협업으로 작품을 제작하고 미션을 수행하며 문제 해결력을 기른다

### 교과 연계 성취 기준

| 과목 | 단원 | 성취 기준 |
|------|------|-----------|
| 기술·가정 | 수송 기술 | 미래 수송기기의 특징을 이해하고 친환경 모형을 제작한다 |
| 기술·가정 | 로봇 기술 | 로봇의 구성 요소(입력·처리·출력)를 이해하고 작동시킨다 |

### 수업 전 30분 사전 준비 체크리스트

**교사 준비 재료 (모둠당)**

| 재료 | 수량 | 비고 |
|------|------|------|
| ELIO 보드 | 1개 | 전날 완충 |
| DC 모터 (바퀴+모터 세트) | 2개 | 앞바퀴 구동용 |
| 컬러 마카골판지 A3 | 3장 | 차체 제작 |
| 30cm 자 | 1개 | |
| 칼, 가위 | 각 1개 | 안전 주의 |
| 글루건 + 글루스틱 | 1세트 | ELIO 본체에는 사용 금지 |
| 빨대 | 수개 | 축·구조물 제작 |
| 벨크로 (찍찍이) | 적당량 | ELIO 탈부착 고정 |

**학생 준비 물품**

| 물품 | 수량 | 비고 |
|------|------|------|
| 스마트폰 | 팀별 1대 | bletoy 앱 사전 설치 |
| 뒷바퀴 재료 | 창의적으로 | 병뚜껑, 단추 등 자유 |
| 꾸미기 재료 | 개인 | 마카, 색종이 등 |

![수업 준비물 예시](/elio-docs/assets/downloads/edu/future-transport-12.png)

### 안전 수칙

- ELIO와 DC 모터는 글루건으로 부착 금지 → **반드시 벨크로 탈부착**
- 칼·가위 사용 시 교사 지도하에 진행
- 실습 시간 종료 5분 전 도구 정리 (팀별 평가 항목)
- 부품 파손 주의 — 파손 시 감점 + 성찰지

## 4차시 수업 계획

### 1차시 — 아이디어 구상 & 디자인

**학습 목표**: 미래 친환경 전기자동차를 조사·구상하고 IDEA 노트에 디자인을 스케치한다.

**준비물**: IDEA 노트 활동지, 스마트폰 (자료 검색용)

#### 도입 (10분)

- 발문: *"앞으로 우리가 이용하게 될 미래 친환경 전기자동차를 디자인해 보자!"*
- 실제 미래 자동차 이미지 5~6장 소개 (교사 준비)
- 수행평가 기준·채점 기준 함께 검토

#### 전개 (30분)

**개인 활동 — IDEA 노트 작성**

1. 자료 검색 (추천 키워드):
   - `자동차 도면`, `자동차 모형`, `자동차 도안`, `자동차 스케치`, `페이퍼 카`
2. 3가지 이상 자동차 디자인 스케치 (420mm × 320mm 도면 칸에)
3. 부품도 그리기: 차체·바퀴·모터 위치 표시
4. 자동차 이름 + 특징 1줄 설명 작성

**모둠 협의 (10분)**
- 팀원 각자 디자인 발표 (1인 2분)
- 제작할 최종 디자인 1개 선정
- 팀명·팀원 명단 기록

#### 정리 (5분)

- 선정 디자인 앞 칠판에 간략 발표 (팀별 30초)
- 다음 시간 재료 확인

**평가 포인트**: 개인 IDEA 노트 스케치 3가지 이상, 특징 설명 작성 여부

---

### 2차시 — 자동차 모형 제작

**학습 목표**: 골판지와 재료를 활용해 선정된 자동차 모형을 제작하고 ELIO를 탑재한다.

**준비물**: 교사 준비 재료 전체, 개인 꾸미기 재료

#### 도입 (5분)

- 작품 예시 사진 소개
- 오늘의 목표: "ELIO가 탑재되고, 모터 2개가 연결된 차체 완성"
- 글루건 안전 사용법 재확인

#### 전개 (35분)

**Step 1. 차체 뼈대 제작 (15분)**
- 골판지 A3로 바닥판·측면·지붕 재단
- 30cm 자로 정확히 측정 후 칼로 절단
- 글루건으로 차체 조립

**Step 2. 앞바퀴 + 모터 연결 (10분)**
- DC 모터 2개를 차체 앞부분에 좌우 배치
- 모터에 바퀴 연결
- **벨크로로 ELIO 보드를 차체 중앙에 고정** (글루건 사용 금지!)

**Step 3. 창의적 뒷바퀴 제작 (10분)**
- 팀 아이디어로 뒷바퀴 만들기 (병뚜껑·단추·빨대 등 활용)
- 볼캐스터 활용 가능

#### 정리 (5분)

- 차체 완성 여부 확인
- ELIO 탈부착 테스트 (벨크로 점검)
- 미완성 팀: 다음 시간 5분 추가 작업 허용

**평가 포인트**: 차체 완성도, 벨크로 탈부착 여부, 모둠 협업 과정

---

### 3차시 — ELIO 연결 & 스마트폰 제어

**학습 목표**: ELIO와 DC 모터를 연결하고 스마트폰 앱으로 자동차를 직접 제어한다.

**준비물**: ELIO 보드, 스마트폰 (bletoy 앱 설치 완료), DC 모터 연결 케이블

#### 도입 (5분)

- ELIO 구성 소개: 보드·앱·BLE 통신 구조 설명 (1분)
- 목표 확인: "오늘 끝나면 스마트폰으로 내 자동차가 달린다"

#### 전개 (35분)

**Step 1. DC 모터 연결 (10분)**
```
DC 모터 (빨간선) ──→ ELIO DC1 포트 (+)
DC 모터 (검은선) ──→ ELIO DC1 포트 (-)
두 번째 모터   ──→ DC2 포트 동일하게
```
- 케이블이 없다면: 3.5mm 이어폰 잭 / RJ11 전화선 / RJ45 랜선 모두 사용 가능

**Step 2. ELIO 전원 ON + 앱 연결 (5분)**
1. ELIO 전원 버튼 1초 누르기 → 파란 LED 점멸 확인
2. bletoy 앱 실행 → 스캔 → "ELIO_XXXX" 선택
3. 파란 LED 점등(연결됨) 확인

**Step 3. 스마트폰으로 자동차 구동 (20분)**
- 조이스틱으로 전진·후진·좌회전·우회전 테스트
- 모터 방향이 반대라면: 앱 설정에서 역방향 변경 또는 케이블 좌우 교체
- 속도 조절: 슬라이더로 50% → 100% 비교

**💡 팁: 한쪽 모터만 돌아가는 경우**
- DC1 / DC2 포트 구분 확인
- 케이블 접촉 불량 → 다시 꽂기
- 배터리 부족 → 충전 후 재시도

#### 정리 (5분)

- 전원 OFF 확인
- 구동 성공 팀 박수
- 다음 시간 미션 안내

**평가 포인트**: ELIO 연결 성공, 4방향 제어 가능 여부

---

### 4차시 — 미션 수행 & 발표

**학습 목표**: 자동차를 운전하여 미션을 수행하고 제작 과정을 발표한다.

**준비물**: 완성 자동차, 미션 코스 (교사 사전 설치), 평가지

#### 도입 (5분)

- 미션 설명 + 규칙 안내
- 동선 배치: 기술실 뒤편 또는 복도 활용

#### 전개 (30분)

**🏁 Mission 1 — 장애물 피해 이동**

```
출발선 ──[30cm 폭 도로]──[장애물1]──[오르막 장애물2]── 목적지
```

| 규칙 | 내용 |
|------|------|
| 도로 폭 | 30cm |
| 장애물 | 장애물 1: 쓰러지면 라인오버 1회 |
| 오르막 | 옆으로 떨어지면 라인오버 1회, 앞으로 이동 후 재도전 |
| 라인오버 | 3회 → 1점 감점 |
| 제한 시간 | 3분 초과 시 도전 실패 |

![Mission 1 도식](/elio-docs/assets/downloads/edu/future-transport-13.png)

**🚛 Mission 2 — 이삿짐 박스 운송** *(선택 과제)*

| 규칙 | 내용 |
|------|------|
| 미션 | 박스를 자동차로 출발선 → 목적지까지 운반 |
| 조건 | 박스를 자동차에 부착하거나 넣을 수 없음 |
| 이탈 | 이동 중 박스 떨어지면 라인오버 1회 |
| 제한 시간 | 3분 |
| 허용 | 미션 해결을 위해 자동차 구조 개조 가능 |

![Mission 2 도식](/elio-docs/assets/downloads/edu/future-transport-14.png)

#### 발표 & 정리 (10분)

- 팀별 1분 발표: "우리 팀 자동차 이름, 특징, 어려웠던 점"
- 교사 피드백
- 다음 확장 활동 소개 (스크래치 코딩, 센서 추가 등)

**평가 포인트**: 미션 수행 점수, 발표 내용, 협업 과정

## 📋 평가 기준 (25점)

### 개인 활동지 (10점)

| 항목 | 만점 | 평가 기준 |
|------|------|-----------|
| 자동차 디자인 스케치 | 4점 | 3가지 이상 ✅, 2가지 △, 1가지 이하 ❌ |
| 특징·설명 기술 | 3점 | 창의성·구체성 |
| 부품도 그리기 | 3점 | 모터·바퀴·ELIO 위치 표시 여부 |

### 모둠 활동 (15점)

| 항목 | 만점 | 평가 기준 |
|------|------|-----------|
| 작품 완성도 | 5점 | 차체·바퀴·ELIO 탑재 완성 |
| ELIO 구동 성공 | 4점 | 스마트폰 4방향 제어 가능 |
| 미션 수행 | 4점 | Mission 1 완주 + 라인오버 횟수 |
| 협업·정리정돈 | 2점 | 실습 도구 정리, 팀 협력 |

## 🚀 확장 활동 (자유학기 연계 +13차시)

4차시 기본 수업 완료 후 자유학기제·동아리로 확장 가능:

### 스마트폰 제어 미션 아이디어

| 미션 | 내용 |
|------|------|
| 자동차 축구 | 탁구공·골프공을 드리블해 골대에 넣기 |
| 서보 조향장치 | 서보모터로 앞바퀴 조향 구현 |
| 속도 경쟁 | 가장 빠른 자동차 만들기 |
| 자동차 씨름 | 상대 자동차를 원 밖으로 밀어내기 |
| 로봇 팔 | 여러 서보모터로 로봇팔 제작 |

### PC 코딩 연계 미션 (Entry·Scratch·Python)

| 미션 | 필요 부품 | 난이도 |
|------|-----------|--------|
| 인공지능 자동차 (장애물 회피) | 초음파 센서 | ★★☆ |
| 라인 트레이서 | 적외선 센서 | ★★☆ |
| 밀당 자동차 (일정 거리 유지) | 초음파 센서 | ★★★ |
| 미로 탈출 | 초음파 + 라인 센서 | ★★★ |

### 추가 부품 소개

| 부품 | 용도 |
|------|------|
| USB 동글 | Entry·Scratch PC 연결 |
| 초음파 센서 | 장애물 감지 |
| 적외선 센서 | 라인 트레이서 |
| 서보모터 | 조향장치, 로봇팔 |
| N20 기어드모터 | 정밀 속도 제어 |
| 듀얼모터 드라이버 | 모터 2개 동시 제어 강화 |
| 볼캐스터 | 자유롭게 회전하는 뒷바퀴 |
