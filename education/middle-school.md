# 🏫 중학교 기술 교과 연계 가이드

> ELIO를 활용한 **중학교 기술·정보 교과 로봇 단원** 12차시 수업 가이드입니다.

---

## 교사를 위한 안내

### 수업 목표

- 로봇의 구성 요소(입력·처리·출력)를 이해한다
- 스마트폰과 로봇의 BLE 통신 원리를 파악한다
- 블록 코딩으로 로봇을 직접 제어하는 경험을 한다

### 30분 사전 준비 체크리스트

- [ ] ELIO 보드 충전 상태 확인 (USB-C, 수업 전날 완충 권장)
- [ ] 스마트폰 bletoy 앱 사전 설치
- [ ] USB 동글 PC 연결 테스트 (Entry HW 앱 실행 확인)
- [ ] 학생 좌석 배치 (2인 1조 권장)
- [ ] 여분 케이블·모터 준비

### 교과 연계

| 과목 | 단원 | 연결 내용 |
|------|------|-----------|
| 기술 | 로봇 단원 | 로봇 구성 요소, 작동 원리 |
| 정보 | 피지컬 컴퓨팅 | 센서·액추에이터, 블록 코딩 |

## 12차시 커리큘럼 개요

| 차시 | 주제 | 유형 |
|------|------|------|
| 1 | ELIO 언박싱 + 스마트폰 연결 | 실습 |
| 2 | 앱으로 모터·서보 직접 제어 | 실습 |
| 3 | 로봇의 구성 요소 이해 (이론) | 이론 |
| 4 | RC 카 조립 + 주행 테스트 | 실습 |
| 5 | Entry 설치 + 첫 번째 블록 | 실습 |
| 6 | 블록으로 RC 카 자동 주행 | 실습 |
| 7 | 센서(초음파·라인) 이해 + 실험 | 실습 |
| 8 | 센서 기반 장애물 회피 코딩 | 실습 |
| 9 | 라인 팔로잉 챌린지 | 실습 |
| 10 | 창작 프로젝트 기획 | 설계 |
| 11 | 창작 프로젝트 제작 | 실습 |
| 12 | 발표 + 피어 리뷰 | 발표 |

## 차시별 상세 (템플릿)

> ⚠ **[B5 PDF 수령 후 각 차시 본문을 작성합니다]**  
> 현재 수령 대기 중인 B5 PDF 자료를 기반으로 차시별 상세 학습 내용·학습지·평가 기준이 추가될 예정입니다.

### 1차시 — ELIO 언박싱 + 스마트폰 연결

**학습 목표**: ELIO 구성품을 파악하고 스마트폰 앱으로 첫 연결에 성공한다.

**준비물**: ELIO 보드, 충전 케이블, 스마트폰

**도입 (5분)**
- "여러분의 스마트폰으로 로봇을 제어한다면?"

**전개 (35분)**
- 언박싱 체크리스트 확인
- bletoy 앱 설치 → BLE 연결
- 모터 테스트 (앱 조이스틱)

**정리 (5분)**
- 오늘 배운 것: BLE(블루투스) 통신, 앱-하드웨어 연결

**평가**
- 스마트폰으로 ELIO가 움직이는가? (Y/N)
