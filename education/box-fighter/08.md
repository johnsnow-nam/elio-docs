# 단원 8: 순차와 반복 이해하기 2

## 학습목표

| # | 목표 |
|---|------|

## 1. 라이트봇 어플을 설치하세요

앗에서 블록코딩하는 방법을 배웠습니다.

어렘게 영어로 코딩하지 않아도 멋진 작품을 만들 수 있습니다.

라이트봇이라는 게임이 있습니다. 이 게임도 블록코딩을 해서 여러 미션을 해결합니다.

지정한 곳에 블록 다 커먼 되는 게임입니다.

라이트봇 또는 Lightbot이라고 검색합니다.

> 📷 [이미지: Google Play에서 Lightbot 검색 화면]

라이트봇을 설치합니다.

> 📷 [이미지: Lightbot - Code Hour 설치 페이지]

설치가 다 되었는지 확인합니다.

> 📷 [이미지: Lightbot 게임 인터페이스]

---

## 2. 순차미션을 해결하세요

앱을 실행합니다. 화면 오른쪽 위에서 언어를 선택할 수 있습니다. 태극기를 선택합니다.

> 📷 [이미지: 언어 선택 화면 (다국어 플래그)]

화면 왼쪽 위에서 라이트봇 종류를 고를 수 있습니다. 클릭할 때마다 모양이 바뀝니다.

> 📷 [이미지: 라이트봇 종류 선택 화면]

새로운 스프라이트

> 📷 [이미지: 새로운 스프라이트 (문어, 고양이)]

구더하고 싶은 스프라이트를 선택하고 구덩합니다.

> 📷 [이미지: Scratch Jr 스프라이트 선택 화면]

다른 스프라이트를 선택하면 그림과 같이 모양이 바뀝니다.

> 📷 [이미지: 블록 코딩 인터페이스 (다양한 블록 도구)]

고양이에 코딩한 것을 복사하면 무대에 스프라이트가 보입니다. X표시를 하면 스프라이트를 선택하는 화면이 됩니다.

> 📷 [이미지: 스프라이트 삭제 버튼]

그리던 그림과 같이 무대가 바뀝니다.

> 📷 [이미지: 무대 배경 변경 화면]

무대 배경을 바꿀 수도 있습니다. 빨간색으로 표시한 곳을 클릭하고 원하는 배경을 선택합니다.

> 📷 [이미지: 배경 선택 아이콘]

확인 버튼을 선택합니다.

> 📷 [이미지: 확인 버튼 (체크 마크)]

그러면 그림과 같이 무대가 바뀝니다.

> 📷 [이미지: 배경이 변경된 무대]

---

## 3. 반복미션을 해결하세요

2번째는 반복 미션입니다. 반복 미션을 선택합니다.

블록을 순서대로 나열하고 어떤 부분이 반복되는지 확인합니다. 이번 미션은 앞으로 4번 가는 블록이 반복되는 것 같습니다.

> 📷 [이미지: 반복 미션 1 - P1 (반복 패턴 식별)]

블록을 순서대로 나열하고 어떤 부분이 반복되는지 확인합니다. 이번 미션은 앞으로 4번 가는 블록이 반복되는 것 같습니다.

> 📷 [이미지: 반복 미션 - 블록 배열]

반복 코드를 PROC1에 넣습니다.

> 📷 [이미지: PROC1 함수 정의 블록]

P1 블록을 사용하면 PROC1 안에 있는 블록이 순서대로 실행됩니다.

> 📷 [이미지: P1 블록 사용 예]

이번 미션은 그림과 같이 코딩하면 됩니다. 어떤 부분이 반복되는지 잘 파악해야 합니다.

> 📷 [이미지: 코딩 완료 예]

중요한 것은 MAIN에 들어있는 블록만 실행합니다.

> 📷 [이미지: MAIN 블록 실행 흐름]
