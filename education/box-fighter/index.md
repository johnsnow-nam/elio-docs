# 📦 박스 파이터 워크북 Q1

> **대상**: 초등 고학년 · 중학생 | **구성**: 12단원 | **원본**: 2020년 ELIO 공식 워크북

ELIO 박스 파이터 교육 키트의 공식 워크북입니다. ELIO 보드와 스마트폰 앱으로 조립→제어→코딩을 단계적으로 배웁니다.

---

## 단원 목록

| 단원 | 제목 | 핵심 학습 |
|:----:|------|----------|
| [1](/elio-docs/education/box-fighter/01/) | 처음 만나는 엘리오 | ELIO 소개, 포트 구성, 앱 설치, BLE 연결 |
| [2](/elio-docs/education/box-fighter/02/) | 깜빡이는 LED | 전기·전압·전류 기초, LED 극성, IO 포트 제어 |
| [3](/elio-docs/education/box-fighter/03/) | DC모터와 서보모터 | 모터 원리, 출력 반전, 서보 연결·제어 |
| [4](/elio-docs/education/box-fighter/04/) | 박스 파이터 만들기 | 키트 조립, 모터·LED 배선, 이동 방향 원리 |
| [5](/elio-docs/education/box-fighter/05/) | 박스 파이터 경주하기 | 레이싱, 풍선 게임, 수학 코스 미션 |
| [6](/elio-docs/education/box-fighter/06/) | 재활용품으로 자동차 | 박스·빨대로 메이킹, 창의 설계 |
| [7](/elio-docs/education/box-fighter/07/) | 순차와 반복 이해하기 1 | Scratch Jr, 순차 실행, 반복·무한반복 블록 |
| [8](/elio-docs/education/box-fighter/08/) | 순차와 반복 이해하기 2 | Lightbot, 순차/반복 미션, 함수(PROC) 개념 |
| [9](/elio-docs/education/box-fighter/09/) | LED 코딩하기 | 앱 블록으로 IO LED 제어, 밝기·깜빡임·난수 |
| [10](/elio-docs/education/box-fighter/10/) | DC/서보모터 코딩하기 | -100~100, 변수 정하기/바꾸기, 조건 반복 |
| [11](/elio-docs/education/box-fighter/11/) | 박스 파이터 코딩하기 | 선택(조건), 방향 함수, LED 동시 제어 |
| [12](/elio-docs/education/box-fighter/12/) | 박스 파이터 코딩대회 | 장애물 코스, 댄스, 서보 막대로 운반 |

---

## 준비물

| 필수 | 선택 |
|------|------|
| ELIO 보드 | 외부 안테나 (원거리 제어 시) |
| 박스 파이터 키트 (DC모터×2, 볼캐스터, 배터리 등) | 추가 LED, 서보모터 |
| 스마트폰 (iOS/Android) | PC (Entry/Scratch 연동 시) |
| [bletoy 앱](/elio-docs/quickstart/) | Scratch Jr 앱 (단원 7), Lightbot 앱 (단원 8) |

---

## 학습 흐름

```
[단원 1-3] 기초 이해          → ELIO 파악 + 전기/모터 원리
[단원 4-6] 하드웨어 조립      → 박스 파이터 완성 + 메이킹
[단원 7-8] 알고리즘 사고      → Scratch Jr / Lightbot으로 순차·반복
[단원 9-11] 앱 블록 코딩     → LED·모터·함수로 자율 주행 로직
[단원 12]  코딩대회           → 장애물·댄스·운반 미션 종합
```
