# 단원 3: DC모터와 서보모터

## 학습목표

| # | 목표 |
|---|------|
| 1 | DC모터와 서보모터가 무엇인지 알 수 있습니다. |
| 2 | DC모터를 움직일 수 있습니다. |
| 3 | 서보모터를 움직일 수 있습니다. |

---

## 1. DC모터와 서보모터를 살펴보자

실생활에서 사용하는 모터는 크게 3가지 종류가 있습니다. 바로 DC모터, 서보(Servo)모터, 스텝(Stepper)모터입니다.

**DC모터:**
DC모터는 전기를 주면 계속 회전하는 모터입니다. 선풍기에 들어가는 모터가 바로 DC모터입니다. 회전방향과 속도를 바꿀 수 있지만 원하는 각도만 회전하는 것은 불가능합니다.

> 📷 [이미지: 노란색 플라스틱 케이스의 DC모터 - 검은색 타이어 바퀴와 원통형 모터 몸체]

**서보모터:**
서보모터는 원하는 만큼 회전할 수 있는 모터입니다. 서모터 안에 돌바퀴기 여러 개 있어서 원하는 만큼 회전할 수 있습니다. 회전 방향과 속도뿐만 아니라 회전각도도 바꿀 수 있습니다. 전기를 줄 때마다 일정한 각이만큼(스텝-step)씩 움직이는 것이죠.

> 📷 [이미지: 파란색 서보모터 - 회전축에 흰색 혼(horn)이 장착된 컴팩트한 모터]

---

## 2. DC모터를 움직여요

모터를 어떻게 회전할 수 있을까요? 모터 안에는 코일과 자석이 들어있습니다. 이 코일에 전기가 흐르면 전자와 자석이 서로 힘을 만듭니다.

이 힘을 전자력이라고 합니다. 플래밍이라는 과학자가 전자력의 원리를 발견했죠.

> 📷 [이미지: 플래밍의 왼손 법칙 다이어그램 - N극과 S극의 자기장 사이에서 전류 흐름과 힘의 방향을 보여주는 손가락 표시]

프래밍의 오른손 법칙에 따르면 플러스극과 마이너스극 위치에 따라 플러스극과 마이너스극 위치를 바꾸면 코일의 움직이로 회전합니다. DC 모터를 보면 2개의 선이 있습니다. 이 2개의 선을 바꿔서 연결하면 반대 방향으로 회전합니다.

> 📷 [이미지: DC모터의 두 연결선 - 빨간색(+)과 검은색(-)으로 표시된 전원 케이블]

모터를 상하 콘트롤에 연결합니다.

> 📷 [이미지: 엘리오 앱 화면 - 위/아래 방향 컨트롤이 표시된 터치 인터페이스]

그리고 DC-1을 선택합니다.

| 타겟 속성 | 모터 선택 |
|---------|---------|
| DC-1    |         |
| DC-2    |         |

엘리오에서 반대로 회전시키는 것을 '슬릭 반전'이라고 합니다. '반전'은 무엇인가를 바꾼다는 것입니다.

모터를 반대 방향으로 회전하려면 '출력 반전'을 사용합니다.

| 타겟 속성 | 모터 선택 |
|---------|---------|
| 장치     | DC-2    |
| 사용 범위 | -100% ~ 100% |
| 출력 반전 |         |
| 기본 출력 | 0%      |
| 보정값   | 0%      |

회전방향을 바꾸를 바꿀 때를 기준으로 합니다. 출력반전을 사용하지 않으면 시계방향으로 회전합니다.

> 📷 [이미지: DC모터 회전 방향 제어 - 위/아래 컨트롤러로 전진/후진 방향을 나타내는 다이어그램]

모터를 상하 콘트롤에 한 개 더 연결합니다.

> 📷 [이미지: 엘리오 앱 제어 화면 - 두 개의 위/아래 방향 컨트롤이 표시된 인터페이스]

그리고 DC-2를 선택합니다. '출록 반전'은 선택하지 않습니다.

상하 콘트롤에도 모터를 2개 연결할 수 있습니다.

좌우 콘트롤에도 모터를 2개 연결할 수 있습니다.

좌우 콘트롤을 오른쪽으로 옮직일 때는 기준으로 합니다. 좌우 콘트롤을 오른쪽으로 옮겼을 때 출력반전을 사용하지 않으면 시계반대 방향으로 움직입니다. 반대로 출력 반전을 사용하면 시계반대방향으로 움직입니다.

---

## 3. 서보모터를 움직여요

이번에는 서보모터를 사용하여 코드 하는 법을 배웁 보겠습니다.

서보모터는 원하는 각만큼 회전할 수 있는 모터입니다. 박스 파이터에서 사용하는 엘리오는 0도에서 180도까지 회전할 수 있습니다.

> 📷 [이미지: 서보모터의 구조 - 파란색 몸체에 회전축과 흰색 혼(horn)이 장착된 모습]

앨리오에 서브모터 2개를 연결할 수 있습니다. 서모터를 보면 선이 3개 있습니다. 갈색선은 마이너스극과 연결하고 빨강선은 플러스극과 연결합니다. 선이 하나 남죠? 남은 선은 S1 또는 S2로 표시한 신호 연결합니다.

**서보모터 선 3개의 역할:**
- **갈색(검은색)**: GND (음극, -)
- **빨간색**: 5V (양극, +)
- **주황색**: 신호(S1 또는 S2)

> 📷 [이미지: 엘리오 제어 보드 핀 배치도 - IO 포트(1-4), 전원 포트(3V/5V), 서보모터 포트(S1/S2)가 표시된 마이크로 컨트롤러]

서모터 3개의 선을 노란색으로 표시한 곳에 연결할 수 있습니다.

| I/O 포트 (4개) | 전원포트 | 서보 모터 포트 |
|--|--|--|
| 1, 2, 3, 4 | 3V, 5V | S1, S2 |

S1연결합니다.

| I/O 포트 | 전압포트 | 서보모터 |
|---------|---------|---------|
| - 1 - 3 | - 3V | - 5V S1 |
| - 2 - 4 | - 5V | - 5V S2 |

모터차림 -100에서 100까지 값을 줄 수 있어서 서보모터를 움직일 수 있습니다.

모터와 서보모터를 엘리오에 연결합니다.

> 📷 [이미지: 엘리오 앱 제어 화면 - 위/아래 방향 컨트롤로 서보모터 제어, 상태 표시줄에 SERVO 0° 값 표시]

SERVO-1을 선택합니다.

| 타겟 속성 | 모터 선택 |
|---------|---------|
| SERVO-1 |         |
| SERVO-2 |         |

| 타겟 목록 | 타겟 속성 | 완료 |
|---------|---------|------|
| 위치 | Up-Down | > |
| 메인 출력 | | |
| 타겟 속성 | | |
| 장치 | SERVO-1 | > |
| 사용 범위 | -90% ~ 90% | > |
| 출력 반전 | | |
| 기본 출력 | 0% | > |
| 보정각 | 0% | > |

상하 콘트롤을 움직여서 서보모터가 어떻게 움직이는지 확인합니다.

반대 방향으로 움직이면 출력반전을 사용합니다.
