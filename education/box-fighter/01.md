## 1. 엘리오는 무엇일까요?

영화 '토이스토리'처럼 쓸모없어진 장난감을 다시 살릴 수 있습니다. ELIO는 고장 난 장난감이나 재활용품에 연결해 스마트폰으로 움직이게 하는 보드입니다.

- 모터·전기 지식이 없어도 **스마트폰 앱**으로 제어할 수 있습니다.
- 코딩을 몰라도 앱의 모델 편집으로 다양한 장난감을 만들 수 있습니다.

**하드웨어 vs 소프트웨어**

| 구분 | 설명 | 예시 |
|------|------|------|
| **하드웨어** | 손으로 만질 수 있는 장치 | 컴퓨터, 스마트폰, ELIO 보드 |
| **소프트웨어** | 장치에 명령을 내리는 프로그램 | 앱, 코딩 블록 |

> 📷 [이미지: 여러 가지 장난감 더미 — ELIO로 연결 가능한 재활용 소재 예시]
> 📷 [이미지: ELIO 보드 외관 사진]

## 2. 엘리오 사용방법을 배워요

### 보드 버튼 · LED

> 📷 [이미지: ELIO 보드 상단 — ①외부스위치 ②전원버튼 ③상태LED ④외부안테나 위치 표시]

| 번호 | 이름 | 설명 |
|------|------|------|
| ① | 외부 스위치 | 장난감 내부에 내장 시 전원 스위치로 활용 |
| ② | 전원 버튼 | 1번 누름: 켜기 / 연속 2번: 끄기 / 길게: 초기화 |
| ③ | 상태 LED | 파란색 깜빡임: 미연결 / 파란색 점등: 연결됨 / 빨간색: 배터리 부족 |
| ④ | 외부 안테나 | 먼 거리 제어 시 안테나 연결 |

### 전면 포트 (배터리·DC)

> 📷 [이미지: ELIO 전면 — 배터리, DC-1, DC-2 커넥터 (각 -/+ 표시)]

| 포트 | 용도 |
|------|------|
| 배터리 | 전원 공급 |
| DC-1 | DC 모터 1번 연결 |
| DC-2 | DC 모터 2번 연결 |

### 후면 포트 (IO·전압·서보)

> 📷 [이미지: ELIO 후면 — I/O 포트(1~4), 전압포트(3V/5V), 서보모터(S1/S2) 다이어그램]

| 포트 | 설명 |
|------|------|
| **I/O 1~4** | LED 연결 (빨간=+극, 검은=-극). LED 4개 동시 연결 가능 |
| **전압포트 3V/5V** | 외부 부품에 3V 또는 5V 전압 공급 |
| **서보모터 S1/S2** | 갈색=-극 / 빨강=+5V / 노랑=신호(S1 또는 S2) |

ELIO 한 보드로 **DC 모터 2개 + 서보모터 2개 + LED 4개**를 동시에 제어할 수 있습니다.

## 3. 엘리오 어플을 설치해요

> 📷 [이미지: Google Play 검색창 "엘리오"]
> 📷 [이미지: "ELIO - DIY 블루투스 콘트롤러" 앱 화면 (별점·설치 버튼)]

1. 스마트폰 앱 검색창에서 **"엘리오"** 검색
2. **ELIO - DIY 블루투스 콘트롤러** 설치 (현재 앱: [bletoy](/elio-docs/quickstart/))
3. 앱을 실행하면 **토이 모델 선택** 화면이 나타납니다

### C.A.T. 개념 (앱 핵심 구조)

> 📷 [이미지: 앱 편집 화면 — ①컨트롤러 배치 ②타겟 추가 ③모델 이미지 변경 설명도]

ELIO 앱은 **C.A.T.** (고양이🐱) 구조로 작동합니다.

| 역할 | 설명 | 예시 |
|------|------|------|
| **C**ontroller | 화면에서 사용자가 조종하는 UI | 상하 패드 ↕, 좌우 패드 ↔, 자유이동 패드, 버튼 |
| **A**ctor | 컨트롤러가 가진 역할 분담 | Left-Right 액터, Up-Down 액터 |
| **T**arget | 실제 출력 부품 | DC 모터, 서보모터, LED(IO) |

**모델 만들기 순서:**
1. 메뉴 **+** 버튼 → 모델 이름 입력 (예: "나만의 장난감")
2. 도구 상자에서 원하는 **컨트롤러**를 1초 눌러 화면에 드래그
3. 도구 상자에서 **타겟**(모터·LED)을 컨트롤러 위에 올려 연결
4. **완료** 버튼으로 저장

---

## 4. 엘리오와 어플을 연결해요

> 📷 [이미지: 앱 화면에서 "ELIO_93B3" 기기가 검색된 페어링 화면]

**연결 순서:**
1. ELIO 전원 버튼을 한 번 누릅니다
2. **파란 LED 깜빡임** 확인 (아직 연결 안 된 상태)
3. 앱 실행 → **페어링 버튼** 누르기
4. 목록에서 **ELIO_XXXX** 선택
5. 파란 LED가 **깜빡임을 멈추고 점등** → 연결 성공

> 앱 하단 상태바(DC / SERVO / IO 수치)가 표시되면 정상 연결입니다.
