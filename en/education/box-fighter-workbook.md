# Box Fighter curriculum map (Q1 workbook, Feb 2020)

> **English summary** of a Korean **ELIO “Box Fighter”** education kit workbook (126 pages, internal PDF). The full workbook with screenshots and worksheets remains in the original PDF. Use this page for **navigation**, **learning goals**, and **key concepts**. For the latest hardware and app (e.g. **bletoy**), follow the [**Korean version**](/elio-docs/education/box-fighter-workbook/) and [Quick start](/elio-docs/en/quickstart/).

---

## What the kit is

- **2× DC motors** + **caster** on a small **box** chassis, optional **LEDs** and **servos**.  
- Control via **phone app** (legacy docs say search “ELIO” in the store; current public docs: **bletoy** on iOS/Android).  
- Pedagogy: **C.A.T.** — **C**ontroller, **A**ctor, **T**arget when mapping UI widgets to **DC / SERVO / IO**.

---

## 12 main chapters (outline)

1. **Meet ELIO** — HW/SW, power, LED status, **Bluetooth pairing**, ports.  
2. **LED** — basic electricity, **LED polarity**, **button / vertical** controllers, on/off.  
3. **DC & servo** — motor types, **output invert**, **vertical/horizontal** stick mapping.  
4. **Assemble** Box Fighter — **motor direction table** for forward / back / spin.  
5. **Games** — race, **balloon + pin**, **math digit** line following on floor.  
6. **Upcycled car** — craft + ELIO; related Korean unit: [upcycling car activity](/elio-docs/education/elementary-upcycling-vehicle/).  
7–8. **Scratch Jr** & **Lightbot** — sequence, loops, procedures (separate apps).  
9. **Block coding** — IO LED levels, blinking, **random** for lighting effects.  
10. **DC/servo** blocks — -100~100, **variables** (set / change by).  
11. **Box Fighter** — **if/else**, **functions** for drive directions + **LED** indicators.  
12. **Contest** — obstacle, dance, **grip** with servos and sticks.

---

## Motor spin vs motion (simplified, from the workbook)

How **left** and **right** wheels should spin to get **translation / rotation** depends on **mechanics**; the workbook’s table (forward / back / left spin / right spin) is a **teaching reference** — use **output invert** in the app so the physical robot **matches** the table after wiring.

---

## Safety

- Hot glue, blades, thumbtacks, balloons — **supervised** for children.
