# 💻 Coding Platforms

> ELIO works with **any coding environment** — from block coding beginners to Python professionals.

---

## 🗺 Platform Selection Guide

| Platform | Target Users | Connection | Requirements |
|----------|-------------|------------|--------------|
| [**Entry**](/elio-docs/platforms/entry/) | Elementary/Middle school, Teachers | USB Dongle | ELIO + USB Dongle + PC |
| [**Scratch 3.0**](/elio-docs/platforms/scratch/) | All ages, Global | USB Dongle | ELIO + USB Dongle + Chrome |
| [**Python**](/elio-docs/platforms/python/) | Middle school~University, Makers | UART direct | ELIO + USB-UART adapter |

---

## 🔌 Two Connection Paths

### Path 🅱 Via USB Dongle (Entry / Scratch)
```
PC / Chrome ──USB── [USB Dongle] ──BLE── ELIO
```
- **Dongle required** (sold separately, ~$8 USD)
- Optimized for block coding

### Path 🅲 UART Direct (Python)
```
PC ──USB-UART adapter──TX/RX/GND── ELIO
```
- **No dongle needed** — only a USB-UART adapter required
- Ideal for text coding and AI projects
- **ELIO Gen 3 (ELIO-52810) only**
